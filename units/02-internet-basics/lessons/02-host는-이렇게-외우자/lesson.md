핵심 개념을 주제별로 정리했다.


## Host · 네트워크에 연결된 컴퓨터

컴퓨터라고 하면 보통 책상 위 PC나 노트북을 떠올립니다. 하지만 네트워크에서 말하는 Host(호스트)는 모양이나 크기로 정하지 않습니다. 스마트폰, 태블릿, 웹 서버처럼 네트워크에 연결되어 데이터를 주고받는 컴퓨터를 호스트라고 부릅니다. 성능이 높은 컴퓨터를 워크스테이션이라고 부르기도 하지만, 워크스테이션이라는 이름이 호스트 여부를 정하는 것은 아닙니다.

집에서 Wi-Fi에 연결한 스마트폰은 동영상 데이터를 요청하고 받습니다. 회사의 서버는 직원의 요청을 받아 파일을 보내 줍니다. 두 기기의 모양과 역할은 달라도 네트워크 통신에 참여한다는 점에서 모두 호스트입니다. 이 강의에서는 먼저 Host를 ‘네트워크에 연결되어 통신하는 컴퓨터’라고 기억합니다. 뒤에서 IP 주소를 배울 때는 IP가 호스트를 찾는 데 쓰인다는 점으로 연결하세요.

## Switch · 네트워크를 이루는 쪽

네트워크에 연결된 기기는 크게 네트워크를 이용하는 쪽과 기기 사이의 연결을 만들어 주는 인프라 쪽으로 나눠 볼 수 있습니다. 이 강의에서는 인프라 역할을 하는 쪽을 넓게 Switch(스위치)라고 부릅니다. 여기서 Switch는 책상 위의 일반 L2 스위치 한 종류만 뜻하는 말이 아니라, 네트워크를 구성하는 여러 장비 역할을 설명하기 위한 묶음입니다.

집의 공유기를 떠올려 보세요. 스마트폰과 노트북은 공유기에 연결되어 인터넷을 사용하고, 공유기는 집 안의 기기와 바깥 네트워크 사이의 통신을 이어 줍니다. 이 예에서 스마트폰은 네트워크를 쓰는 단말 쪽이고, 공유기와 라우터는 네트워크를 이루는 인프라 쪽입니다.

용어를 외울 때 주의할 점이 있습니다. 일반적으로 네트워크에 붙은 장치를 넓게 Host라고 부르는 경우도 있지만, 이 강의의 역할 구분에서는 L2 스위치를 Host에 포함하지 않습니다. 여기서는 ‘Host는 연결된 컴퓨터’, ‘Switch는 인프라 역할’이라는 강의의 분류 기준으로 기억하세요.

## End point · 네트워크를 이용하는 쪽

Endpoint(엔드포인트)는 네트워크 연결의 끝에서 서비스를 이용하거나 제공하는 장치를 가리킵니다. End가 ‘끝’이라는 뜻이므로 단말·단말기라고도 부릅니다. 네트워크 장비 사이의 연결을 구성하기보다 그 연결을 통해 실제 작업을 하는 기기입니다.

집에서 스마트폰으로 동영상을 보면 스마트폰은 영상 서비스를 이용하는 엔드포인트입니다. 네트워크 프린터는 컴퓨터가 보낸 인쇄 작업을 받아 출력하는 엔드포인트입니다. 회사의 서버도 사용자 요청을 받아 서비스를 제공하므로 엔드포인트에 포함됩니다. 따라서 엔드포인트를 ‘사용자 손에 들린 기기’로만 한정하면 안 됩니다.

앞 페이지의 구분과 연결하면, 스위치 쪽은 네트워크를 이어 주고 엔드포인트 쪽은 그 네트워크를 사용합니다. 노트북과 프린터는 엔드포인트, 두 장비를 연결하는 공유기나 스위치는 인프라 장비입니다. **기억할 말:** Endpoint는 네트워크를 이용하거나 서비스를 제공하는 끝단의 장치입니다.

## Client와 Server

Client(클라이언트)와 Server(서버)는 엔드포인트가 통신에서 맡는 역할을 나타냅니다. 내 노트북 브라우저에서 웹 페이지를 열면 브라우저가 페이지를 보내 달라고 요청합니다. 요청을 시작한 노트북 쪽이 클라이언트입니다. 요청을 받은 웹 서버는 페이지 데이터를 돌려줍니다. 답을 제공하는 쪽이 서버입니다.

서버는 반드시 커다란 전용 장비를 뜻하지 않습니다. 서비스를 제공하도록 실행 중인 컴퓨터나 프로그램을 서버라고 부를 수 있습니다. 한 컴퓨터도 상황에 따라 클라이언트가 되기도 하고 서버가 되기도 합니다. 내 노트북이 웹 사이트를 조회할 때는 클라이언트지만, 다른 컴퓨터에 파일을 제공하도록 설정하면 파일 서버 역할을 할 수 있습니다.

그러므로 이 두 역할은 기기의 고정된 종류가 아닙니다. 통신 한 건에서 누가 요청을 시작하고 누가 서비스를 제공하는지를 나타냅니다. **기억할 말:** Client는 요청하는 쪽, Server는 요청에 응답하거나 서비스를 제공하는 쪽입니다.

## Peer · 두 역할을 함께 하기

일반적인 웹 접속에서는 클라이언트가 요청하고 서버가 응답하므로 역할이 나뉘어 보입니다. P2P(Peer to Peer) 방식에서는 참여자들이 서로 직접 데이터를 주고받으며, 한 참여자가 받는 쪽인 동시에 보내는 쪽이 될 수 있습니다. 이런 참여자를 Peer(피어)라고 합니다.

파일 공유를 예로 들어 보겠습니다. 큰 파일을 여러 조각으로 나눠 내려받는 동안, 내 컴퓨터는 아직 없는 조각을 다른 참여자에게서 받습니다. 이미 받은 조각은 다시 다른 참여자에게 보낼 수도 있습니다. 같은 프로그램이 어떤 조각을 받을 때는 클라이언트처럼, 가진 조각을 전달할 때는 서버처럼 동작하는 셈입니다. 비트토렌트가 대표적인 P2P 사례입니다.

‘클라이언트와 서버’는 역할의 방향을 설명하고, ‘피어’는 두 역할을 함께 할 수 있는 참여자를 설명합니다. 모든 P2P 참여자가 항상 같은 양의 데이터를 주고받는다는 뜻은 아닙니다. **기억할 말:** P2P에서는 한 참여자가 필요에 따라 받고 제공하는 역할을 함께 맡을 수 있습니다.

## Router · 대표적인 L3 스위치

Router(라우터)는 서로 다른 네트워크 사이에서 패킷이 갈 다음 방향을 정하는 장비입니다. 도로로 비유하면 동네와 동네를 잇는 교차로와 비슷합니다. 라우터는 패킷의 목적지 IP 주소를 확인하고, 라우팅 정보에 따라 어느 연결로 내보낼지 선택합니다. IP가 OSI의 L3 네트워크 계층 정보이므로 라우터를 대표적인 L3 장비라고 부릅니다.

집의 공유기는 보통 여러 기능을 한 상자에 함께 넣습니다. 노트북에 무선 연결을 제공하고, 집 안과 바깥 네트워크 사이에서 트래픽을 전달하는 라우터 기능도 수행합니다. 제품 이름이 ‘공유기’여도 그 안에 라우터 역할이 들어 있습니다. 기업 네트워크에서는 라우터, 무선 장비, 스위치가 별도 장비로 나뉘기도 합니다.

IPS 같은 보안 장비도 네트워크 흐름을 살펴 보안 기능을 수행하는 인프라 장비입니다. 원문에서는 이를 보안 스위치라고 묶어 소개합니다. **기억할 말:** 라우터는 목적지 IP를 보고 네트워크 사이의 다음 경로를 고르는 대표적인 L3 장비입니다.

## 보안·관리 목적의 스위치

네트워크에는 단말을 연결하거나 다른 네트워크로 패킷을 전달하는 장비 외에도, 트래픽을 관찰하고 여러 연결을 모으는 특수 장비가 있습니다. 이 페이지에서는 탭 스위치와 애그리게이션 스위치라는 이름을 봅니다. 지금은 내부 동작을 모두 외우기보다 이름과 사용 목적을 연결하는 것이 목표입니다.

탭(Tap) 스위치는 네트워크를 지나가는 트래픽의 복사본을 보안·분석 장비에 전달해 흐름을 관찰하는 용도로 사용됩니다. Aggregation(애그리게이션)은 여러 연결을 모은다는 뜻입니다. 애그리게이션 스위치는 여러 구간의 연결을 모아 상위 네트워크 장비로 이어 줍니다.

제품과 네트워크 설계에 따라 구현은 달라질 수 있습니다. 이 강의의 기본 분류에서는 둘 다 네트워크를 구성하거나 관리하는 인프라 쪽 장비라는 점을 기억하세요. **외울 말:** 탭은 관찰용 흐름 복사, 애그리게이션은 여러 연결을 모으는 역할입니다.

## Host의 역할 구분 정리

집 네트워크의 한 장면으로 개념을 묶어 보겠습니다. 스마트폰에서 웹 페이지를 열면 스마트폰은 네트워크에 연결된 Host이자 서비스를 이용하는 Endpoint입니다. 요청을 보낼 때는 Client 역할을 합니다. 웹 페이지를 제공하는 서버 컴퓨터도 Host이자 Endpoint이며, 서비스를 제공하는 Server 역할입니다. 집의 공유기는 두 쪽을 연결하는 인프라 장비이고 라우터 기능으로 패킷을 전달합니다.

이름이 여러 개 붙는 이유는 각각 다른 질문에 답하기 때문입니다. Host는 네트워크에 연결된 컴퓨터인가, Endpoint는 통신의 끝에서 서비스를 이용하거나 제공하는가, Client/Server는 이번 통신에서 누가 요청하고 응답하는가를 나타냅니다. Peer는 P2P에서 참여자가 보내고 받는 역할을 함께 맡을 수 있음을 설명합니다. 기기 하나에 이름 하나만 붙는다고 생각하지 마세요.

마지막으로 이 단원의 분류 관례도 기억합니다. 여기서는 L2 스위치를 Host에 포함하지 않고 인프라 역할로 구분합니다. **한 줄 암기:** Host는 연결된 컴퓨터, Endpoint는 서비스의 끝단, Client는 요청자, Server는 제공자, Peer는 두 역할을 함께 할 수 있는 참여자입니다.
