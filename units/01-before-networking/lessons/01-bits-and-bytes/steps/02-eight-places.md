# 여덟 자리를 한 묶음으로 보기

한 자리만으로는 켜짐과 꺼짐 두 가지 상태를 적을 수 있어요. 자리를 여러 개 나란히 놓으면 더 많은 모양을 적을 수 있습니다.

예를 들어 아래에는 여덟 자리가 있습니다.

```text
1 0 1 1 0 0 1 0
```

각 자리는 0 또는 1을 나타냅니다. 서로 다른 모양이어도 자릿수가 여덟 개라는 점은 같아요. 비트 여덟 개를 한 묶음으로 부를 때 byte(바이트)라는 이름을 사용합니다.

따라서 위의 모양은 8비트이고, 1바이트입니다. 아직 이 숫자가 어떤 글자나 값을 뜻하는지는 다루지 않아요. 먼저 자릿수와 묶음의 이름을 익힙니다.
