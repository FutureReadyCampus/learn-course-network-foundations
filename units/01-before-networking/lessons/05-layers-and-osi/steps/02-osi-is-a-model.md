# OSI 일곱 계층은 설명을 위한 모형

네트워크의 일을 설명할 때는 아래부터 물리(Physical), 데이터 링크(Data Link), 네트워크(Network), 전송(Transport), 세션(Session), 표현(Presentation), 응용(Application) 계층으로 나누어 볼 수 있어요. 이 일곱 층을 OSI 7계층이라고 부릅니다.

OSI는 통신의 역할을 나누어 생각하도록 돕는 모형이에요. 실제 컴퓨터 안에 일곱 개의 층판이 그대로 들어 있다는 뜻은 아닙니다. 다음에 통신 과정을 배울 때 각 역할을 구분하는 지도로 사용해요.
