# 오늘의 글 쓰기

## 오늘 쓸 글 고르기

하루의 마지막 40분은 오늘 한 봉쇄 조치를 내 말로 남기는 시간입니다. 글은 내 GitHub Pages 포트폴리오에 올립니다. 아직 포트폴리오가 없다면 [Module 3 Unit 1 시작하기 레슨의 「내 기록 남기기: 소개」 페이지](__SITE__/exercises/module/3/unit/1/lesson/1/page/4)부터 시작합니다.

**40분은 이렇게 나눕니다**

| 순서 | 시간 | 하는 일 |
|---|---|---|
| 1. 고르기 | 5분 | 아래 글감 질문 중 하나 고르기 |
| 2. 쓰기 | 25분 | 글 틀을 복사해 내 답을 글로 풀기 |
| 3. 점검 · 올리기 | 10분 | 공개 전 점검을 하고 GitHub 에 올린 뒤 첫 화면 확인하기 |

글감은 보고서 `report_u2.md` 에 적은 답 가운데 가장 오래 고민한 것을 고르면 쉽습니다.

**글감 질문 (실습 2-1 · 2-2)**

1. VIP 계정 `gaeun` 은 잠기지 않았습니다. 경로 정하기에서 이미 `승인 필요` 로 걸렀는데도 조치 함수(`check_policy`)가 정책을 한 번 더 검사하는 이유는 무엇인가요?
2. 계정을 잠갔는데도 `dami` 의 세션 두 개가 남아 있었습니다. 잠금만으로 부족한 이유와, 잠금이 확인된 계정만 세션을 끊게 한 이유를 써 보세요.
3. 계정 잠금, IP 차단, 세션 종료 중 잘못 실행했을 때 가장 피해가 큰 것은 무엇이라고 보나요? 이유를 써 보세요.

**선택 글감 (응용 2-1 · 2-2를 했다면)**

1. 결정이 「승인」인데 실행되지 않은 알림(INC-005)은 왜 그랬나요? 권한 확인이 없으면 어떤 위험이 생길까요?
2. 실패했을 때 재시도 횟수를 3번으로 정한 이유는 무엇인가요? 끝없이 다시 시도하면 무엇이 위험할까요?

세 문장만 써도 한 편의 글입니다. 오늘 막혀서 실습을 다 못 했다면 그 막힌 이야기도 좋은 글이 됩니다. 어디서 멈췄는지 남겨 두면 다음에 나도, 글을 읽는 사람도 도움을 받습니다.

## 글 틀로 쓰고 올리기

설치할 것은 없습니다. Module 3 Unit 1 시작하기 레슨에서 한 것처럼 **GitHub 웹 화면**에서 파일을 만들고 붙여 넣습니다. 글 틀 세 가지는 [「글 틀로 글 쓰기」 페이지](__SITE__/exercises/module/3/unit/1/lesson/1/page/10)에 있습니다.

**1. 글 틀 고르기**

| 오늘 나의 상황 | 고를 글 틀 |
|---|---|
| 실습 2-1 이나 2-2 하나를 글 한 편으로 쓰고 싶다 | `_templates/post-practice.md` |
| 시간이 5분밖에 없다 | `_templates/post-short.md` |
| 실습하다 막혔다 | `_templates/post-stuck.md` |

**2. 새 글 파일 만들기**

1. 내 포트폴리오 저장소에서 `_posts` 폴더를 열고 **Add file › Create new file** 을 누릅니다.
2. 파일 이름은 `날짜-영문제목.md` 모양으로 적습니다. 예: `_posts/2026-11-20-m5-u2-account-lockout.md`
3. 고른 글 틀의 내용을 붙여 넣고, 맨 위 머리말(front matter)을 오늘 Unit 에 맞게 고칩니다.
   ```
   module: 5
   unit: 2
   ```
   - 이 두 줄이 첫 화면 「나의 진행」에서 Module 5 의 **2번** 칸을 채웁니다.
   - `title` 은 내 글의 한 줄 제목으로, `date` 는 오늘 날짜로 바꿉니다.
4. 빈칸을 채우고 **Commit changes** 를 누릅니다.

**3. 코드 올리기**

글에서 소개한 코드는 저장소의 `code/` 폴더에 올립니다. `code` 폴더에서 **Add file › Create new file** 을 누르고, 이름은 Unit 번호가 보이게 적습니다.

- 예: `code/m5_u2_account_actions.py`(실습 2-1), `code/m5_u2_containment.py`(실습 2-2)
- 글 안에는 핵심 몇 줄만 코드 상자로 붙이고, 「전체 코드: `code/m5_u2_account_actions.py`」처럼 위치를 적습니다.

**4. 확인하기**

올리고 1~2분 기다린 뒤 내 사이트 첫 화면을 엽니다. 최신 글에 내 글이 보이고, 「나의 진행」의 Module 5 · 2번 칸이 채워졌으면 끝입니다. 보이지 않으면 저장소의 **Actions** 탭을 먼저 봅니다.

## 막힐 때 힌트

글이 잘 안 풀리면 아래에서 고른 글감에 맞는 힌트를 하나 봅니다.

1. **글감 1(VIP 계정)**: `check_policy` 의 `if user in vip_accounts:` 두 줄과, 실습 2-1 출력 단계 2 의 INC-003 줄(`변경 없음 → 변경 없음 · VIP 계정이라 자동 조치 대상이 아님`)을 붙입니다. 그다음 「경로에서 한 번, 조치 함수에서 한 번」 두 곳에서 막는 이유를, 경로 설정이 틀렸거나 다른 코드가 `lock_account` 를 바로 부른 경우로 나눠 씁니다.
2. **글감 2(세션)**: 실습 2-2 출력 단계 1 의 `['junho']` 와 단계 2 의 `dami` 두 줄(`잠기지 않음 → 잠김`, `세션 2개 → 세션 0개`)을 나란히 붙입니다. 잠금만 했다면 세션 `S-101` · `S-102` 로 무엇을 할 수 있었을지부터 쓰면 글의 절반이 됩니다. `containment.py` 의 `if lock_record["after"] == "잠김":` 한 줄이 `gaeun` 을 어떻게 지켰는지도 덧붙입니다.
3. **글감 3(피해 비교)**: 세 조치를 줄로, 「잘못 실행하면 누가 못 쓰게 되나」 · 「되돌릴 수 있나」를 칸으로 하는 작은 표를 먼저 그립니다. 공유 IP `192.0.2.41` 을 쓰는 `junho` · `hana` 처럼 오늘 데이터의 이름을 예로 들면 글이 구체적이 됩니다.
4. **실행 결과 붙이기**: 터미널 출력은 전부 붙이지 않아도 됩니다. 내 말과 연결되는 두세 줄만 코드 상자(```` ``` ````)로 붙이고, 그 아래에 「이 줄에서 무엇을 보았는지」를 한 문장으로 씁니다. 화면 캡처를 쓰려면 이미지를 `assets/images/` 에 올리고 글에 연결합니다.
5. **막힌 이야기를 쓸 때**: `post-stuck.md` 의 「증상」에 내 출력을 그대로 붙입니다. 예를 들어 실습 2-1 에서 `dami` 가 `잠기지 않음 (확인 실패)` 로 나왔다면, 그 줄과 내가 의심한 곳(5번 `verify_locked` 의 `return` 인지, 6번 `append` 인지)을 적고 어떻게 찾았는지 씁니다.

질문 하나에서 시작해도 막히면 AI 도우미를 써도 됩니다. 붙여 넣는 프롬프트 세 가지(코드 설명 정리 · 글 초안 다듬기 · 내 글 점검)는 [Module 3 Unit 1 시작하기 레슨의 「쓰기 질문과 AI 도우미」 페이지](__SITE__/exercises/module/3/unit/1/lesson/1/page/11)에 있습니다. AI 도우미에게 붙여 넣는 코드와 글에는 비밀키 · 토큰 · 개인정보를 넣지 않습니다.

## 공개 전 점검

**Commit changes** 를 누르기 전에 한 번 더 봅니다.

1. 글과 `code/` 파일에 비밀키 · 토큰 · `.env` 내용이 없다
2. 이메일 · 전화번호 같은 개인정보가 없다
3. 실습 데이터가 아닌 실제 사람의 이름(나와 동료의 실명)이 없다
4. 머리말이 `module: 5`, `unit: 2` 이고, `sample: true` 줄이 없다
