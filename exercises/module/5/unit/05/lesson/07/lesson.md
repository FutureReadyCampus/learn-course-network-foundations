# 핵심 실습 결과 기록 준비

`report_u5.md` 는 두 핵심 실습의 실행 결과를 저장소에 남기는 기술 기록입니다. 문제의 답이나 회고를 쓰는 문서가 아닙니다. 판단 근거와 배운 점은 핵심 실습 뒤 포트폴리오 글에 기록합니다.

1. **[VS Code]** `network-study-notes/soar_response` 에 `report_u5.md` 를 새로 만들거나 기존 파일을 엽니다.
2. 아래 틀을 붙여 넣고 이름을 바꾼 뒤 저장합니다. 실습에서 전체 출력이 요구되면 해당 코드 칸에 붙입니다.


3. 이 파일에는 실행 결과와 확인한 값을 기록합니다. 설명형 답변은 각 실습 아래 정답 펼침에서 확인하고, 고민 과정은 포트폴리오 글에 씁니다.

> **확인** — `report_u5.md` 에 실습 5-1 · 5-2 제목과 출력 칸이 보이면 준비가 끝났습니다.
