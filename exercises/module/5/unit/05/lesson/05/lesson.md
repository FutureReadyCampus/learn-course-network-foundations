# 실습 결과 기록 준비

## 실습 결과 기록 파일 만들기

`report_u5.md` 는 **두 실습의 실행 결과와 판단 근거를 정리하는 작업 기록**입니다. 실습마다 전체 출력과 핵심 질문의 근거를 남겨, 나중에 결과를 다시 확인할 수 있게 합니다.

1. **[VS Code]** 왼쪽 목록에서 `soar_response` 폴더를 오른쪽 클릭 › **New File** 을 누르고, 파일 이름 `report_u5.md` 를 그대로 적고 Enter 를 칩니다. 이미 있으면 새로 만들지 않고 그 파일을 엽니다.
2. 아래 틀의 복사 버튼을 눌러 내용을 붙여 넣고, 제목의 `이름` 을 내 이름으로 바꾼 뒤 저장합니다(`Ctrl + S`, 맥북은 `Cmd + S`).

각 실습을 마칠 때 해당 실습의 출력과 질문에 대한 근거를 이 파일의 같은 항목에 기록합니다. 문제 해결 과정과 배운 점은 실습을 모두 마친 뒤 문제 해결 기록 페이지에서 블로그 글로 남깁니다.

## 실행 결과와 근거를 기록하는 법

> **쓰는 법**
> - 문제를 풀 때마다 그 문제 제목 아래 질문에 답합니다.
> - 질문마다 `쓸 내용:` 에 무엇을 쓰면 되는지 적혀 있습니다. 그대로 `답:` 뒤에 씁니다.
> - 출력이나 코드를 붙여 넣는 질문은 `답:` 아래 빈 코드 상자에 붙여 넣고, 설명은 `답:` 뒤에 씁니다.
> - 「왜」를 묻는 질문은 한 단어로 끝내지 말고, 내 화면에서 본 값이나 배운 내용을 근거로 이유까지 씁니다.
> - [핵심 질문] 표시는 이 실습에서 꼭 알아야 할 핵심 질문입니다. 답을 못 찾았으면 「모름 — 막힌 곳: …」 이라고 씁니다. [핵심 질문]이 없는 질문도 못 적으면 같은 말을 씁니다.


실습 결과 기록은 코드를 작성하거나 실행하는 답안이 아니라, 각 실행의 결과와 이유를 되짚을 수 있게 남기는 기술 기록입니다. 실습 5-1과 5-2의 질문은 해당 실습 페이지에서 확인하고, 답은 이 파일에 적습니다.
