# 실습 결과 기록 준비

## 핵심 실습 결과 기록

`practice_record_u3.md` 는 핵심 실습에서 실행한 코드의 결과와 그 결과를 확인한 근거를 저장소에 보관하는 기술 기록입니다. 실습 3-1과 3-2를 시작하기 전에 아래 틀을 만들어 두고, 각 실습이 끝날 때 실행 결과와 확인한 값을 기록합니다. 이 기록은 기술 결과를 남기며, 문제를 어떻게 이해하고 해결했는지 설명하는 글은 핵심 실습 뒤 GitHub 블로그에 따로 씁니다.

1. **[VS Code]** `anomaly_detection` 폴더에 `practice_record_u3.md` 파일을 만듭니다. 이미 있으면 그 파일을 엽니다.
