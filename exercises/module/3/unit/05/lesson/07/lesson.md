# 보고서 쓰기

## 보고서 파일 만들기

보고서는 **내 답을 적는 파일**입니다. 따로 내려받지 않고, 아래 틀을 복사해 직접 만듭니다. 질문 글은 이 레슨의 다음 페이지들에 있으니, 파일에는 번호와 `답:` 칸만 있습니다.

1. **[VS Code]** 작업 폴더는 `network-study-notes/access_control` 입니다. 왼쪽 목록에서 `access_control` 폴더를 오른쪽 클릭 › **New File** 을 누르고, 파일 이름 `report_u5.md` 를 그대로 적고 Enter 를 칩니다. 이미 있으면 새로 만들지 않고 그 파일을 엽니다.
2. 아래 틀의 **복사** 버튼을 눌러 내용을 붙여 넣고, 제목의 `이름` 을 내 이름으로 바꾼 뒤 저장합니다(`Ctrl + S`, 맥북은 `Cmd + S`).
3. 틀은 두 부분입니다.
   1. 핵심: 꼭 채울 칸은 다섯 칸입니다. `## 실습 5-1` 의 (가) · (나), `## 실습 5-2` 의 상황 2개, `### 질문` (가)입니다. 실습 5-2의 상황 1 · 2는 본보기라 파일에 칸이 없고, 상황 3 ~ 8 가운데 2개를 골라 채웁니다. 다 해도 실습 시간 안에서 30분 안쪽이고, 글쓰기 20분은 따로 있습니다.
   2. 응용(여유가 되면): 나머지 상황 칸, `## 실습 응용 질문` 과 `## 응용 5-1` 은 내가 한 것만 채웁니다. 하지 않은 칸은 비워 둡니다.

## 보고서 쓰는 방법

> **쓰는 법**
> - 문제를 풀 때마다 그 문제 제목 아래 질문에 답합니다.
> - 질문마다 `쓸 내용:` 에 무엇을 쓰면 되는지 적혀 있습니다. 그대로 `답:` 뒤에 씁니다.
> - 출력이나 코드를 붙여 넣는 질문은 `답:` 아래 빈 코드 상자에 붙여 넣고, 설명은 `답:` 뒤에 씁니다.
> - 「왜」를 묻는 질문은 한 단어로 끝내지 말고, 내 화면에서 본 값이나 배운 내용을 근거로 이유까지 씁니다.
> - [핵심 질문] 표시가 붙은 질문은 이 실습에서 꼭 알아야 할 핵심 질문이라 꼭 채웁니다. 답을 못 찾았으면 「모름 — 막힌 곳: …」 이라고 씁니다.
> - [응용] 표시가 붙은 질문은 여유가 되면 해 보세요. 답은 틀의 `## 실습 응용 질문` 칸에 씁니다.

글쓰기는 다음 레슨 「오늘의 글 쓰기」에서 합니다.

**상황 정리** — 상황 3 ~ 8 중 2개를 골라 씁니다. 나머지는 여유가 되면 씁니다. 상황 1 · 2 는 본보기입니다.

#### 상황 1 · 새 직원이 들어옴 (본보기)
- 원인: 데이터 문제입니다. hana 가 입사했는데 `users.json` 에 hana 가 아직 없습니다. 시스템은 사용자 파일에 없는 사람의 요청을 모두 「등록되지 않은 사용자」로 거부합니다.
- 고칠 파일: `config/users.json`
- 어떻게 고치나요: 새로 넣습니다. hana 를 `"hana": {"role": "sales", "employed": true}` 로 `users.json` 에 적습니다. `role` 은 hana 가 맡을 일에 맞는 역할로 정합니다.
- 고친 뒤 확인: hana 의 요청을 다시 판정해서 「등록되지 않은 사용자」가 사라지는지 봅니다.

#### 상황 2 · 퇴사자 계정으로 요청이 계속 들어옴 (본보기)
- 원인: 데이터가 정리되지 않았습니다. dami 는 퇴사했는데 dami 의 정보가 `users.json` 에 그대로 남아 있어서 같은 시도가 계속 들어옵니다. `employed` 가 `false` 이면 요청은 거부되지만, 남은 정보 때문에 퇴사자 계정 점검에는 계속 걸립니다.
- 고칠 파일: `config/users.json`
- 어떻게 고치나요: dami 의 `"employed"` 가 `true` 로 남아 있다면 먼저 `false` 로 바꿉니다. 이미 `false` 이면 그대로 두고, dami 의 정보 전체를 `users.json` 에서 지웁니다.
- 고친 뒤 확인: 같은 요청이 「등록되지 않은 사용자」로 거부되고, 퇴사자 계정 점검이 통과로 바뀌는지 봅니다.
- 더 써 보고 싶은 것(선택): `check_permission` 이 퇴사 여부를 역할 확인보다 먼저 보는 이유는 무엇일까요?
