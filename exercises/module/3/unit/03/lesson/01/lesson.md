# 시작하기

## 목표와 오늘의 계획

지난 Unit 2(권한 주기)에서는 권한을 **주는** 흐름(요청 → 승인 → 예외 권한 부여)을 만들었습니다. 이번에는 반대로 이미 **부여돼 있는 권한** 가운데 필요 없어진 것을 찾는 **접근 점검**을 만듭니다. 찾기까지만 하고, 찾은 권한을 실제로 거두는 일은 다음 Unit 4(권한 거두기)에서 합니다.

**오늘의 계획 (3시간)**

| 순서 | 시간 | 하는 일 |
|---|---|---|
| 1. 시작하기 | 15분 | 이 레슨을 읽고, 이전 Unit 의 파일이 있는지 확인합니다. |
| 2. 실습 | 약 110분 | 핵심 실습 두 개를 차례로 합니다. |
| 3. 글쓰기 | 40분 | 「보고서 쓰기」에서 질문에 답하고, 「오늘의 글 쓰기」에서 글 한 편을 씁니다. |
| 4. 마무리 | 15분 | 실습 3-2 끝의 「이번 Unit 마무리」에서 파일을 확인하고 깃허브에 올립니다. |

실습 3-2 앞에서는 「제공 파일」 레슨의 파일 네 개를 복사해 만듭니다. 글쓰기에서 답하는 질문은 핵심 실습의 질문입니다.

**오늘 만들 것 두 가지** — 두 실습 모두 함수 본문을 직접 씁니다.

| 실습 | 파일 | 함수 | 만드는 것 |
|---|---|---|---|
| 실습 3-1 | `review_list.py` | `build_access_list` | 누가 어떤 권한을 어떤 방법(역할 · 예외)으로 갖고 있는지 한곳에 모은 **현황 리스트** |
| 실습 3-2 | `review_unused.py` | `find_unused` | 사용 이력과 비교해 찾은 **90일 넘게 안 쓴 권한** 후보 |

퇴사 · 만료로 이미 필요 없어진 권한은 「제공 파일」의 `review_rules.py` 가 먼저 걸러 줍니다.

**응용 3-1 ~ 3-3은 선택입니다.** 핵심 실습 두 개와 글쓰기를 마치고 시간이 남을 때 합니다. 응용마다 아래 파일을 직접 만듭니다.

| 응용 | 파일 | 하는 일 |
|---|---|---|
| 응용 3-1 | `review_rules.py` | 퇴사 · 만료 규칙으로 필요 없어진 권한을 찾음 |
| 응용 3-2 | `overprivilege.py` | 두 점검 결과를 합쳐 한 장짜리 리포트를 만듦 |
| 응용 3-3 | `report_exclude.py` | 회수하지 않을 권한을 가려냄 |

응용을 하지 않아도 「제공 파일」 레슨으로 이 세 파일을 모두 갖추므로, 다음 Unit 4 를 그대로 따라갈 수 있습니다.

**이번 Unit 에서 불러 쓰는 이전 파일** — 이번 Unit 의 코드는 Unit 1(권한 정하기)에서 만든 파일만 불러 씁니다. Unit 2(권한 주기)의 파일(요청서 · 승인 파일)은 쓰지 않으므로 따로 준비할 것이 없습니다.

| 불러 쓰는 것 | 들어 있는 파일 | 쓰는 곳 | 없으면 만드는 곳 |
|---|---|---|---|
| 사용자 · 역할 딕셔너리 `USERS` · `ROLES` | `config/users.json` · `config/roles.json` · `rbac.py` | 실습 3-1 | Unit 1 정답 레슨 |
| 예외 리스트 `EXCEPTIONS` · 시각 형식 `TIME_FORMAT` | `config/exceptions.json` · `exception_policy.py` | 실습 3-1 · 3-2 | Unit 1 「제공 파일」 레슨 |
| 설정 파일을 안전하게 읽는 `load_json` | `config_loader.py` | 실습 3-2 | Unit 1 「제공 파일」 레슨 |

Unit 1 정답 레슨에서는 두 JSON 파일을 「실습 1-1 정답」으로, `rbac.py` 를 「실습 1-2 정답」으로 만듭니다. 「제공 파일」 레슨의 파일은 복사해 만듭니다.

이번 Unit 에서 만드는 파일도 뒤에서 이어 씁니다. 실습 3-1 의 `review_list.py` 는 실습 3-2 와 모든 응용에서, 실습 3-2 의 `review_unused.py` 는 응용 3-2 · 3-3 과 다음 Unit 4 가 씁니다.

## 터미널 열고 이전 파일 확인하기

1. **[VS Code]** 왼쪽 목록의 `access_control` 폴더를 오른쪽 클릭 › **Open in Integrated Terminal** 로 터미널을 엽니다.
2. **[터미널]** 위치와 이전 파일을 확인합니다. `pwd` 의 결과가 `…/security-agent-toolkit/access_control` 로 끝나야 합니다.
   ```bash
   pwd
   ls
   ls config
   python -c "from rbac import USERS, ROLES; from exception_policy import EXCEPTIONS, TIME_FORMAT; from config_loader import load_json; print('이전 파일 정상', len(USERS), len(ROLES), len(EXCEPTIONS))"
   ```
   - 마지막 줄의 `python -c "…"` 는 따옴표 안의 파이썬 코드를 파일을 만들지 않고 바로 실행하는 명령입니다. 이전 파일을 불러와 사용자 · 역할 · 예외 개수를 세어 봅니다.
   - 맥북은 `python` 을 `python3` 로 바꿔 칩니다. 마지막 줄에 `이전 파일 정상 6 5 5`(사용자 6명 · 역할 5개 · 예외 5건)가 나와야 합니다.
   - 오류가 나면 시작하기 첫 페이지의 「이번 Unit 에서 불러 쓰는 이전 파일」을 보고 빠진 파일을 만듭니다(`config` 안의 파일은 `config` 폴더에). 그다음 마지막 줄을 다시 칩니다.
3. **파일은 이렇게 만듭니다.** 이번 Unit 의 파일은 모두 레슨의 코드 상자에서 복사해 만들고, 따로 내려받는 파일은 없습니다. 「`파일이름` 파일을 만들어 아래 내용을 붙여 넣습니다」라고 하면:
   1. **[VS Code]** 왼쪽 목록에서 알려 준 폴더를 오른쪽 클릭 › **New File** 을 누르고, 알려 준 **파일 이름을 그대로** 적고 Enter 를 칩니다.
   2. 코드 상자의 복사 버튼으로 내용을 복사해 새 파일에 붙여 넣고, `Ctrl + S`(맥북은 `Cmd + S`)로 저장합니다.
   - 답을 적는 **보고서** `report_u3.md` 는 이 Unit 의 「보고서 쓰기」 레슨에서 복사해 만듭니다.
4. 문제는 **할 일 → 순서**대로 하고, `[창 이름]` 이 지금 쓸 창입니다. 코드를 채울 때는 주석이 말하는 일을 하면 몇 줄이든 맞고, 막히면 「정답」 레슨을 봅니다.

> 실행은 VS Code 의 ▶ 단추가 아니라 **터미널**에서 합니다(맥북은 `python3`). **이전 Unit 의 파일은 고치지 않습니다.** 이번 Unit 에서 만드는 파일은 모두 새 파일입니다.
