# Unit 1 source and presentation

Unit 1 preserves the Wiki reading-edition sequence rather than introducing a new teaching pattern. The source sequence is in `sources/wiki/oeweo-network/lesson-01.md` through `lesson-04.md`; the authored Learn text is copied into the matching Unit Lesson Markdown so later edits do not depend on rebuilding from Wiki headings. Lesson front matter records the source path. Beginner-guide JSON and original diagrams remain preserved under `sources/wiki/oeweo-network/`; Unit-specific animations are stored beside the Lesson that uses them.

This records a source migration and authoring choice. It does not claim measured learning gains or establish a new teaching pattern.
