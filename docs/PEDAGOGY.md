# Unit 1 저작 기록

## 비트와 바이트 첫 Lesson · 2026-10-27

### 참고한 실제 출판사 견본과 관찰한 순서

Learn의 기존 `docs/PEDAGOGY.md`에 기록하고 시각 검토한 i-Scream 2022 개정 초등 수학 3-1 견본, 교과서 84–85쪽(출판사 공식 샘플)을 참고했다. 관찰한 순서는 책갈피 수량이라는 익숙한 대상 → 그림 속 묶음 세기 → 수 모형 → 곱셈 기호 → 대상과 기호가 뜻하는 관계 설명 → 수를 바꾼 새 문제와 독립 적용이다. 이 순서를 정보 단위를 가르치는 데 그대로 옮기지 않고, 상태를 세고 모형화한 뒤 용어를 붙이는 저작 선택으로 적용한다.

출판사 샘플은 학습 효과를 측정한 근거로 해석하지 않는다. 수학 교재의 대상·수 모형·기호 연결을 네트워크 내용에 맞게 바꾼 편집 원칙이다.

### 이 Lesson에서 적용한 순서

전등의 켜짐/꺼짐 두 상태 → 0/1로 나타내는 한 자리(bit) → 여덟 자리를 세어 한 묶음(byte)이라 부르기 → 자릿수는 유지하고 상태만 바꾸기 → 의자 여덟 개의 점유 상태를 독립적으로 나타내기.

전등은 두 상태를 생각하기 위한 모형이라고 분명히 쓰고, 컴퓨터가 실제 전등으로 동작한다고 말하지 않는다. bit/byte를 먼저 다루고 2진수·16진수 변환, 마스크 연산, 용량 단위는 이 Lesson에서 가르치지 않는다.

### 실제 Network 자료 확인

`course-network/studio/wiki/oeweo-network/originals/print.pdf`는 「외워서 끝내는 네트워크 핵심이론 - 기초」의 67쪽 자료다. 2–3쪽은 수강 전제 항목을 나열하며 1 byte=8 bit, 논리 연산, 2진수/16진수, 프로그램/프로세스, OSI, User/Kernel mode 등을 전제한다. 이는 설명 순서가 아니라 기존 강의의 선행지식 목록이다.

같은 자료 6–7쪽은 Layered 구조의 상자 배치와 의존 화살표를 먼저 보이고, 다음 장에서 두 사람의 대화 상황을 제시한다. Wiki 강의 원고는 요소와 관계 → 계층 사이 의존성 → 학교 과정 비유 → OSI에 적용하는 순서다. 이 자료는 이후 Layer Lesson 검토용이며, 이번 bit/byte 설명 순서의 근거로 혼용하지 않는다.
