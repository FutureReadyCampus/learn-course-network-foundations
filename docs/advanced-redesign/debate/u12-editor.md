## 기각 항목 (한 줄)

- R6: `100.64` 한 줄은 CGNAT 복선이라 남긴다.
- R8: Page 이동은 ID 순서를 깨고 흡수는 Page 삭제다.
- R9: p2/p5 합치기는 각 Page 분량이 적정해 실익이 없다.
- R10: p2+p3 합치면 L4가 5 Page다.
- R19: 포트 표기 문단은 L2 p1 흐름에 필요하다.
