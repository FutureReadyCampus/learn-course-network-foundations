# Unit 15 편집자 결정

독자(R1~R21)·검수자(T1~T24) 지적을 저울질했다. 리드 결정(서버 구역 `192.168.40.0/24`, NIDS 표현, IPS 위치, 로그 상관, 도쿄 서버, IPsec 전제, "원고" 삭제, NAC 순서, 피날레)은 그대로 적용했다.
