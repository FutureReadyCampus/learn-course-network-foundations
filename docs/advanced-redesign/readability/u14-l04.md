- 수치(문장 수 / 평균 / 최대 / 70자 초과): 전 126 / 40.4 / 97 / 7 -> 후 150 / 34.8 / 71 / 1 (남은 1개는 주소 두 개가 든 문장) (문단 수·Page 7개·퀴즈 14개·question_placements 14개 그대로)

- 손대지 않은 곳: 퀴즈 전부(문장이 이미 짧고 보기 길이 균형·정답 의미 보호), 표 셀, 「가져갈 것」·「이번에 쓴 생각법」 상자(형식 유지), 터널 구간·주소 수치·UDP 4500 등 사실 문장

## 대표 수정

1. Page 3 (VPN 클라이언트는 누구에게 말을 걸까?): "집 공유기를 지나면 ... `192.0.2.123`이 되지만(Page 4에서 자세히), 노트북이 연결을 여는 목적지는 ... `198.51.100.25`다." -> "...이 된다(Page 4에서 자세히). 하지만 ... 목적지는 ...다." / 97자 한 문장을 대비 구조로 분리.
2. Page 3: "SSL VPN이면 바깥 포장이 TLS 연결로 달라질 뿐(앞 Lesson), ...같다." -> "SSL VPN이라면 바깥 포장만 TLS 연결로 달라진다(앞 Lesson). 안쪽과 바깥을 나눠 보는 생각은 같다." / '~일 뿐, ~같다' 이중 절 분리.
3. Page 5 (노트북에 주소가 왜 두 개일까?): "VPN용 주소 풀 `10.10.99.0/24`에서 주소 하나를 빌려준다." -> "주소 하나를 빌려준다. 빌려줄 주소는 VPN용 주소 풀(주소를 모아 둔 범위) ...에서 나온다." / 처음 나온 '주소 풀' 풀이.
4. Page 5: "하나는 ...(집 구간용), 다른 하나는 ...가상 인터페이스의 ...(사내망용)이다." -> 두 문장으로 나누고 가상 인터페이스에 풀이 추가 / 96자 나열 문장.
5. Page 6 (집에서 나간 패킷은 어떻게 포장될까?): "이 패킷을 클라이언트가 암호화해 한 겹 포장하고, 바깥 헤더를 노트북에서 본사 SG로 붙인다." -> "클라이언트는 이 패킷을 암호화해 한 겹 포장한다. 그리고 노트북에서 본사 SG ...로 가는 바깥 헤더를 붙인다." / 두 동작을 한 문장씩.
6. Page 6: "바깥 출발지가 ... 바뀌어 인터넷에 나간다." -> "공유기는 바깥 출발지를 ... 바꿔 내보낸다." / 주어를 앞세워 누가 바꾸는지 분명히.
7. Page 6: "터널 목적지가 닿지 않는다면 ...을 보고, 터널은 열렸는데 AI가 안 열린다면 ...를 본다." -> 두 문장으로 분리 / 두 경우를 한 문장에 묶어 헷갈림.
8. Page 7 (다른 지사 SG에 붙으면 길이 어떻게 될까?): "지난달 쇼룸 지원 출장 때 쓰던 도쿄 SG(...) 접속 프로필이 노트북에 그대로 남아 있다." -> 프로필 풀이를 넣고 "이 프로필은 도쿄 SG(...)로 접속한다."로 분리 / 처음 나온 '접속 프로필'.
9. Page 7: "도쿄 SG는 ... 열어 둔 상태였고, 거기서 풀린 패킷이 ... 들어 있었다." -> 두 문장으로 분리 / 원인과 결과 분리.
10. Page 9 (서버는 박 팀장을 누구로 볼까?): "그 응답은 서울 SG에서 포장되어 터널을 지나 집 노트북에서 풀린다." -> "서울 SG가 그 응답을 포장해 터널로 보내고, 집 노트북이 포장을 푼다." / 피동을 주어 있는 능동으로.
11. Page 9: "안쪽 통신 주소는 ...이고, 바깥 터널 주소는 ...이다." (80자) -> 두 문장으로 분리 / 주소 두 쌍을 한 문장씩.
12. Page 10 (VPN을 켜면 모든 인터넷이 회사로 갈까?): "대가는 회사 회선에 부담이 몰리고, 길이 멀어져 느려지며, 외부 사이트가 ...본다는 점이다." -> "대가는 세 가지다. ... 몰리고, ... 느려지고, ... 본다." / 나열 대가를 풀어 쓰기.
