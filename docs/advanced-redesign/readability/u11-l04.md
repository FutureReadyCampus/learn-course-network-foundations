## 대표 수정

1. Page 「AI 요청을 누군가 대신 보내 준다면?」
   - 이전: 직원의 PC가 "…맡기겠다"고 정해서 보내므로, 프록시는 보통 목적지 서버보다 클라이언트 가까이에 놓인다.
   - 이후: …정해서 보낸다. 그래서 프록시는 보통 …놓인다.
   - 이유: 원인과 결과를 두 문장으로 나눴다.
2. 같은 Page
   - 이전: 캐시, 접근 정책, 기록, 내용 검사는 …얹는 기능이다. 대신 받아서 대신 보내니, 그 사이에 …
   - 이후: 캐시(받은 응답을 저장해 두고 다시 쓰는 기능), … 프록시는 요청을 한 번 받아서 보낸다. 그 사이에 …
   - 이유: 처음 나온 용어에 풀이를 달고 '대신 …대신' 되풀이를 줄였다.
3. 같은 Page
   - 이전: '프록시' 칸에 적혀 있었다. (처음 보는 서버 주소가)
   - 이후: '프록시' 칸(요청을 대신 보내 줄 서버를 적는 칸)에 처음 보는 서버 주소가 적혀 있었다.
   - 이유: 낯선 용어를 앞에서 풀었다.
4. Page 「브라우저에 프록시 주소를 넣으면?」
   - 이전: 지우는 시험 삼아 … 프록시 프로그램을 띄우고, 자기 PC(…) 브라우저의 프록시 설정에 주소 …, 포트 …을 넣었다. (104자)
   - 이후: …띄웠다. 그리고 자기 PC(…) 브라우저의 프록시 설정에 … 넣었다.
   - 이유: 동작 두 개를 두 문장으로 나눴다.
5. 같은 Page
   - 이전: 40대 PC에 일일이 설정을 넣을 수는 없으니, 회사는 …자동 구성 파일을 관리 도구로 한꺼번에 배포하기도 한다.
   - 이후: …넣을 수는 없다. 그래서 회사는 …자동 구성 파일(어떤 요청을 어느 프록시로 보낼지 적은 파일)을 …
   - 이유: 문장을 나누고 처음 나온 용어를 풀었다.
6. Page 「프록시 안에는 연결이 몇 개일까?」
   - 이전: 504 Gateway Timeout은 "…", 502 Bad Gateway는 "…"는 뜻의 상태 코드다. (113자)
   - 이후: 504 …는 뜻이다. 502 …는 뜻이다. 둘 다 HTTP 상태 코드다.
   - 이유: 두 코드를 각각 한 문장으로 풀었다.
7. 같은 Page
   - 이전: 평문 HTTP 사이트라면 …그대로 보이고, HTTPS 통로를 요청했을 때는 …보여 주기도 한다.
   - 이후: …그대로 보인다. HTTPS 통로를 요청했을 때는 …
   - 이유: 경우를 나눠 문장 하나에 하나씩 담았다.
8. Page 「AI 서비스에는 누구 주소가 보일까?」
   - 이전: 한결디자인 PC는 사설 주소(192.168.10.x)를 쓰므로, 인터넷으로 나갈 때 회사 경계 장비가 출발지를 …바꿔 보낸다. (93자)
   - 이후: …를 쓴다. 인터넷으로 나갈 때는 회사 경계 장비가 출발지를 …바꿔 보낸다.
   - 이유: 사실과 그 결과를 나눴다.
9. Page 「'무료 우회 프록시', 써도 괜찮을까?」
   - 이전: 낯선 사람이 밖에서 운영하면 보안 구멍이 되고 회사가 안에서 운영하면 …통제 지점이 된다. (92자, 앞 절과 한 문장)
   - 이후: 중계 서버라는 구조는 그대로다. 낯선 사람이 밖에서 운영하면 보안 구멍이 되고, 회사가 안에서 운영하면 …
   - 이유: 같은 구조라는 말과 운영 주체에 따른 차이를 분리했다.
10. 같은 Page
   - 이전: 회사 입장에서 핵심 위험은 …흘러가고, 그 경로가 회사 기록 어디에도 남지 않는다는 것이다.
   - 이후: 회사가 걱정할 핵심 위험은 두 가지다. …흘러가고, 그 경로가 …남지 않는다.
   - 이유: '~는 것이다' 명사절을 풀고 위험 두 가지를 먼저 알렸다.
11. Page 「한 번 더 돌아가면 무엇을 잃을까?」
   - 이전: 더 큰 대가는 의존이다.
   - 이후: 더 큰 대가는 모든 요청이 프록시 한 대에 기대게 된다는 점이다.
   - 이유: 추상 명사 '의존'을 동사로 풀었다.
12. 퀴즈 u11-l04-p02-q02 prompt
   - 이전: …전사에 배포한 다음 주, … 앱은 정상 작동하는데도 기록이 0건이다.
   - 이후: …회사 전체에 배포한 다음 주, …잘 남는다. 하지만 … 앱은 정상 작동한다. 그런데도 프록시 기록은 0건이다.
   - 이유: '전사'를 쉬운 말로 바꾸고 긴 문장을 나눴다.
