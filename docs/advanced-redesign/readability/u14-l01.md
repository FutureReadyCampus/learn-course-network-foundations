## 대표 수정

1. Page 3 (지사 직원은 본사 AI를 어떻게 쓰지?): "물건이 매장에 도착해야 하고(닿을 것), ...하며(노출 금지), ...(보호)." -> 세 조건을 세 문장으로 분리 / 한 문장에 조건 셋이 몰려 있었다.
2. Page 9 (VPN이면 전용 회선만큼 안전할까?): "지우의 일은 'VPN을 켜면 끝'이 아니라 ... 포함한다는 점은 분명하다." (86자) -> "...끝이 아니다. 키와 계정 관리, ... 모두 지우의 몫이다." / 길고 주어가 불분명했다.
3. Page 9: "회선 사업자 쪽에서 장애나 사고가 나면 영향을 받고, 전용 회선도 ... 소용이 없다." -> "전용 회선도 ... 영향을 받는다. 양쪽 끝 장비와 ... 소용이 없다." / 주어를 앞세워 둘로 분리.
4. Page 8 (지사용 VPN과 재택용 VPN): "이때 끝에 있는 것이 게이트웨이(G)인지, 단말(E, Endpoint)인지에 따라 유형이 나뉜다." -> "터널의 끝이 게이트웨이(G)인지 단말(E, Endpoint: 노트북 같은 사용자 기기)인지에 따라 VPN 유형이 나뉜다." / 단말 풀이 추가, '이때' 제거.
5. Page 8: "노트북에는 VPN 클라이언트가 설치되고, 이를 원격 접속 VPN이라고 부른다." -> "VPN 클라이언트(접속용 프로그램)를 설치한다. 이 방식을 ... 부른다." / 피동 제거와 용어 풀이.
6. Page 7 (VPN은 인터넷 위에 무엇을 씌울까?): "VPN은 새 선을 까는 일이 아니라, ... 논리적인 통로를 하나 더 만드는 일이다." -> 두 문장 + "소프트웨어로 만든 가상의 길" / '논리적'을 풀어 줌.
7. Page 7: "터널링은 패킷을 한 번 더 포장해서 나르는 구조이고, 암호화는 그 위에 더해지는 보호다." -> "포장해서(캡슐화) 나르는 구조다. 암호화는 그 위에 더하는 보호다." / 캡슐화 용어를 포장과 연결, 피동 제거.
8. Page 7: "자동차가 ... 훤히 보이지만, 터널에 들어가면 ... 보이지 않는다." -> "훤히 보인다. 하지만 터널에 들어가면 ..." / 대비되는 두 장면 분리.
9. Page 3: "...이미 있는 인터넷 위에 보호를 덧붙이는 VPN이다." -> "...보호를 덧붙여 사설망처럼 쓰는 VPN(가상 사설망)이다." / VPN이 처음 나오는 자리에 풀이.
10. Page 1 (사내 AI는 왜 사무실 밖에선 안 보일까?): "집 노트북은 사설망 바깥에 있는 공용망의 한 점일 뿐이므로 서버에 닿지 못하는 것이 정상이다." -> "...한 점일 뿐이다. 그러니 서버에 닿지 못하는 것이 정상이다." / 원인과 결론 분리.
11. Page 6 (인터넷을 그냥 쓰면 뭐가 걱정일까?): "...IPsec의 AH와 ESP가 무엇을 지켜 주는지..." -> "IPsec(VPN에 쓰는 보안 규칙 묶음)의 AH와 ESP가 각각 무엇을 지키는지" / 처음 나오는 IPsec 풀이.
12. Page 5 (아예 우리만의 회선을 깔면?): "다른 회사의 트래픽과 섞이지 않고, ... 정할 수 있으며, ... 보기 쉽다." -> 세 장점을 두 문장으로, 트래픽(오가는 데이터) 풀이 / 나열형 한 문장 분리.
