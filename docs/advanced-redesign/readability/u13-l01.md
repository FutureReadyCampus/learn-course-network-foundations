- 고친 문장 약 30개, 나눈 문장 약 28개 (Page 8개·문단 수·퀴즈 16개·question_placements 16개 그대로)
- 풀이를 더한 용어: 가용성, L7(응용 계층), VIP(가상 IP), 서버 풀, 세션, 헬스 체크, 에이전트, 이중화·하트비트

## 대표 수정

1. Page 1 (한결봇은 왜 ... 느려졌을까?): "...묻고, 서 이사는 ...따진다." -> 두 문장 / 말하는 사람이 둘이라 나눔.
2. Page 1: "...사실상 쓰기 어려워지고, 이는 서비스의 가용성을 떨어뜨린다." -> "...쓰기 어려워진다. 이것이 서비스의 가용성(필요할 때 쓸 수 있는 정도)이 떨어지는 것이다." / 지시어 "이는" 풀고 용어 풀이 추가.
3. Page 1: 지우의 보고 인용(78자) -> "이렇게 보고했다." + 짧은 인용 두 문장 / 한 문장 인용이 길었다.
4. Page 2 (포트 포워딩을 서버 여러 대로 늘리면?): "시연 때만 ... 열었다가 닫았다"(82자)와 "그 방식이 아니라 ... 새로 세운다"(95자) -> 네 문장 / 한 문장에 시연 과거·새 구성이 섞여 있었다.
5. Page 2: "L4는 전송 계층이라는 뜻으로, ... 나눈다." -> "...뜻이라서 IP 주소와 포트까지만 본다. 요청 내용까지 읽는 L7(응용 계층)은 뒤에서 다룬다." / L7이 풀이 없이 먼저 나옴.
6. Page 2: "...로드 밸런서를 세우고, ...공개 주소를 이 장비에 둔다. ...고르고, ...구성한다." -> 네 문장 / 구성 변화를 한 걸음씩.
7. Page 3 (손님은 왜 주소 하나만...): "이 대표 주소를 VIP라 부르며, VIP는 ..." -> "VIP(가상 IP)라 부른다. VIP는 ..." / 용어 처음 나온 자리 풀이.
8. Page 3: "로드 밸런서가 받고, 서버 풀 ...로 넘긴다." -> "...받는다. 로드 밸런서는 서버 풀(요청을 나눠 맡는 서버 묶음) ...로 넘긴다." / 서버 풀 풀이와 문장 분리.
9. Page 4 (앞말을 잊는다면?): "세션 고정(sticky session)이다." 뒤에 "세션은 한 손님이 이어 가는 대화 한 묶음이다." 추가 / 세션 용어 풀이.
10. Page 7 (모델을 싣는 중인 서버로 ...): 헬스 체크를 "ping에 답하나"로만 하면 ... 정상으로 보인다 -> "헬스 체크(서버 상태를 주기적으로 확인하는 검사)가 알려 준다. ...하면 부족하다. ...보이기 때문이다." / 처음 쓰는 용어 풀이, 78자 분리.
11. Page 7: "에이전트가 CPU·메모리·디스크 여유를 서버 상태를 모아 보는 별도 서버(관리 서버)나 로드 밸런서로 보내면 ..." -> 세 문장 / 어긋난 조사와 85자 한 문장.
12. Page 8 (서버 한 대를 빼도 ...): "...무정지라 부르지만, 진행 중이던 연결은 끊길 수 있어서 ...절차(드레이닝)를 둔다."(98자) -> 세 문장 / 대조와 이유를 각각 한 문장으로.
