## 대표 수정

1. Page 1 (일본 고객 느림): "합쳐 왕복이 20~30번 안팎(가정)이고 서울과 도쿄 사이 왕복이 50ms(가정)라면 ... 3~4.5초가 된다." -> "이렇게 쌓인 왕복이 20~30번 안팎(가정)이라고 하자. 서울과 도쿄 사이 ..." / 전제와 계산을 분리.
2. Page 1: "TCP와 TLS 연결을 맺는 데만 몇 번 오가야 하고, ... 되풀이된다." -> "~오가야 한다. 게다가 ... 되풀이된다." / 한 문장에 연결 두 종류가 엮여 있었다.
3. Page 1: "한 곳의 L4 ... 풀어 주지만 ... 풀지 못한다." -> "풀어 준다. 하지만 ... 풀지 못한다." / 대조를 문장 둘로.
4. Page 2 (DNS 라운드 로빈): "DNS 답은 TTL 동안 리졸버, 운영체제, 브라우저에 보관된다." -> "리졸버, 운영체제, 브라우저는 DNS 답을 TTL 동안 보관한다." / 피동을 능동으로, 주어를 앞세움.
5. Page 2: "TTL이 짧으면 DNS 질의가 늘고, 모든 캐시가 ... 지킨다는 보장도 없어서 ..." -> "늘어난다. 또 ... 보장이 없어서 ..." / 대가 두 가지를 분리.
6. Page 3 (CNAME): "지역이 정해지는 곳은 ... 단계이고, 일본 쪽 손님에게는 ...이, 한국 쪽 손님에게는 ...이 돌아간다." -> 두 문장 / 주소 둘이 든 긴 문장.
7. Page 4 (리졸버): "권한 DNS 서버가 보는 것은 손님 PC의 IP가 아니라 ... 리졸버의 IP다." -> "손님 PC의 IP를 보지 않는다. 대신 ... 리졸버의 IP를 본다." / "~하는 것은 ~가 아니라" 구조를 풀음.
8. Page 4: "일부 리졸버는 ECS로 손님 주소의 앞부분(서브넷)을 함께 보낸다." -> "ECS를 쓴다. ECS는 ... 질문에 함께 실어 보내는 방식이다." / 처음 나온 약어를 한 문장으로 풀이.
