# U12 Lesson 2 문장 가독성 검토

- 요약: 본문 문장 수 123 -> 141. 평균 길이 42.5 -> 38.1자. 최대 95 -> 76자. 70자 초과 13 -> 3(아래 이유로 유지).
- 고친 곳: 본문 문장 약 22개, 퀴즈 prompt 3개. 문장을 둘 이상으로 나눈 곳 17개.
- 풀이를 더한 용어: NAT 변환표(바꾼 주소의 짝을 적어 두는 표), NAT 세션 목록(지금 변환 중인 통신의 목록), Local/Remote/External(택배 대장의 보낸 사람·받을 곳·접수번호에 대응), 매핑(주소의 짝), 필터링(받을 패킷을 가려내는 규칙), 유휴 시간(아무 통신 없이 흐른 시간), N:1 공유(여러 PC를 바깥 주소 하나로 묶어 내보냄).
- 손대지 않은 곳: 퀴즈 보기 text/feedback(길이 균형·정답 의미 유지), 「가져갈 것」·「생각법」 상자(형식 유지, 70자 초과 2줄), 표, 72자 문장 `지우 PC(...)와 디자인팀 PC(...)가 ... 요청을 보낸다.`(주소 두 개가 길이를 차지해 읽기 부담이 작음).
- 문단 수(51), Page 수(7), 퀴즈 수(14), question_placements, 보기 길이 균형(audit ok)은 그대로. 빌드 통과.

## 대표 수정

1. [AI API의 답장은 어떻게 내 PC를 찾을까?] 이 두 현상은 공유기 안의 표 하나, NAT 변환표로 함께 설명된다. -> 이 두 현상은 공유기 안의 표 하나로 함께 설명된다. 그 표가 NAT 변환표, 곧 바꾼 주소의 짝을 적어 두는 표다. / 피동 정리와 용어 풀이.
2. [AI API의 답장은…] 지우 PC가 ... 부르면 답은 ... 바깥 주소로 온다. -> 부른다. 그러면 답은 ... 온다. / 86자 조건문을 둘로.
3. [AI API의 답장은…] 요청이 나가는 길에서 ... 기록되는지, 응답이 돌아오는 길에서 ... 쓰이는지를 차례로 볼 것이다. -> 먼저 ... 본다. 이어서 ... 본다. / 나열을 순서 두 문장으로.
4. [공유기를 나설 때 패킷의 무엇이 바뀔까?] 공유기 안쪽에서 이 패킷을 보면 출발지가 A인데, 바깥쪽에서 보면 B로 달라져 있다. -> 안쪽에서 이 패킷의 출발지는 A다. 그런데 바깥쪽에서 보면 B로 달라져 있다. / 86자 대조를 두 문장으로.
5. [공유기를 나설 때…] ...Outbound라고 부르는데, 이때 공유기는 ... 바꾼다. -> Outbound라고 부른다. 이때 공유기는 ... 바꾼다. / 95자, 용어 정의와 동작을 분리.
6. [공유기를 나설 때…] 그리고 이렇게 바꾸는 것만으로는 부족하다. 바뀐 짝 ... 적어 둬야 나중에 응답이 왔을 때 원래 PC를 찾을 수 있다. -> ...적어 둬야 한다. 그래야 나중에 ... 찾는다. / 95자, 이유를 따로 세움.
7. [변환표 한 줄에는 무엇이 적힐까?] Local은 ..., Remote는 ..., External은 ...다. -> 세 문장으로 나누고 대장의 보낸 사람·받을 곳·대표 접수번호에 각각 대응. / 낯선 세 열 이름을 앞 문단 비유에 연결.
8. [변환표 한 줄에는…] Remote 열은 ... 알려 주고, 필터링이 상대를 가리는 방식일 때 수신 허용 조건으로 쓰인다. -> 두 문장 + 필터링 풀이. / 처음 나온 용어 풀이.
9. [돌아온 답장은 어느 PC로 갈까?] 여기서 중요한 점이 하나 있다. 이 되돌림은 ... -> 이 되돌림은 ... / 뜸 들이는 문장 삭제. 이어지는 77자 문장도 둘로 나눔.
10. [동시에 물어도 답이 왜 안 섞일까?] ...이 방식이 바로 이것이고, 일반 공유기의 N:1 공유가 이렇게 가능하다. -> ...바로 이것이다. 일반 공유기가 여러 PC를 바깥 주소 하나로 묶어 내보내는 것(N:1 공유)도 이 방식 덕분이다. / N:1 풀이.
11. [박 팀장의 요청은…] 대장에 적는 사람은 지금까지 안내 데스크 자신이었지만, ...적을 기회가 없다. -> 지금까지는 안쪽 직원이 연락하면 안내 데스크가 대장에 적었다. 하지만 ... / 79자, 주어가 먼 비유를 동작 순서로.
12. [박 팀장의 요청은…] 길이 열린다는 것은 곧 노출이 된다는 뜻이기도 해서, 그 대가는 다음 Lesson에서 따진다. -> 길이 열리면 안쪽이 바깥에 노출되기도 한다. 그 대가는 ... / 추상 명사 "노출이 된다"를 동사로.
