- 요약: 본문 문장 수 119 -> 130. 평균 길이 49.6 -> 45.7자. 최대 114 -> 104자(측정기가 따옴표 닫힘 뒤 마침표를 문장 끝으로 못 봐 대화 인용과 다음 문장을 한 문장으로 센 값, 실제로는 분리됨). 70자 초과 15 -> 5(남은 5개는 아래 이유로 유지).
- 고친 곳: 본문 문장 약 17개, 퀴즈 prompt 4개. 문장을 둘로 나눈 곳 14개.

- 손대지 않은 곳: 퀴즈 보기 text/feedback(길이 균형·정답 의미 유지), 「가져갈 것」·「생각법」 상자(형식 유지, 70자 초과 3줄), 표, SPOF 정의 문장(76자, 영문 풀이 괄호 포함이라 유지).
- 문단 수, 퀴즈 수, question_placements, 보기 길이 균형(audit ok)은 그대로.

## 대표 수정

1. [AI 요청은 어떤 장치를 거쳐 나갈까?] 노트북도, 외부 AI 채팅 서비스도 그대로인데 장소만 바뀌었다. -> ...도 그대로다. 바뀐 것은 장소뿐이다. / 인용문에 붙어 있던 114자 문장을 끊음.
2. [AI 요청은 …] 지우는 ... 패킷을 버린 장치를 찾고, 그 장치가 왜 ... 쥐고 있는지 따져 본다. -> 찾는다. 그리고 그 장치가 왜 ...도 따져 본다. / 93자 두 목표를 두 문장으로.
3. [AI 요청은 …] 고속도로 비유로 말하면, 차가 막혀 못 갔을 때 의심할 곳은 ...톨게이트들이다. -> 비유를 떠올려 보자. 차가 못 갔을 때 ... / 도입과 설명을 분리.
4. [AI 요청은 …] 집에서는 공유기 하나가 이 출구 역할을 다 맡았다면, 회사에서는 ... -> 다 맡았지만, 회사에서는 ... / 가정형 어미를 대조형으로 바로잡음.
5. [방화벽은 어느 쪽이 안인지 어떻게 알까?] Outbound인 패킷은 ISP 라우터 입장에서는 들어오는 패킷이고, A를 '안쪽'... 약속일 뿐이다. -> ...패킷이다. A를 '안쪽'... / 95자를 두 사실로 나눔.
6. [방화벽은 …] 지우는 규칙을 읽을 때 'Inbound냐 Outbound냐'보다 '...'를 먼저 풀어 적기로 했다. -> 'Inbound냐 Outbound냐'를 먼저 따지지 않기로 했다. 대신 '...'를 먼저 풀어 적었다. / 94자 비교 구문을 둘로.
7. [회선을 늘렸는데 왜 그대로 느릴까?] ...올렸지만, 체감 속도는 그대로였다(...가정이다). -> 올렸다. 그래도 체감 속도는 그대로였다(...). / 77자 분리.
8. [회선을…] 처리량이 약 150Mbps라면, 회선이 300Mbps일 때도 ... -> ...라고 하자. 그러면 ... / 가정을 먼저 세우고 결론을 따로.
9. [회선을…] 처리량을 높이는 방법으로 가속기가 있다. 처리 프로그램까지 -> 처리 프로그램(소프트웨어)까지 ... 이 문제를 줄이려고 쓰는 것이 가속기다. / 가속기가 해결하는 문제를 앞 문장과 연결.
10. [회선을…] ...재전송, 서버 처리 시간도 영향을 주고, 설명서의 처리량은 ...달라진다는 점도 함께 기억하자. -> 두 문장 + 재전송 풀이. / 81자, 용어 풀이.
11. [주소만 볼까, 내용까지 볼까?] 서 이사는 "..."라고 했고, 박 팀장은 "..."라고 맞섰다. -> 두 문장으로 분리. / 두 사람의 주장을 각각 한 문장에.
12. [주소만…] 표 셀: 복호화 설정 -> 복호화(암호 풀기) 설정 / 처음 나온 용어 풀이.
13. [퀴즈 p02 q02] ...라고 하는데, 같은 시각 재택 중인 동료는 ... -> 라고 한다. 그런데 ... / 접속 대조를 문장 경계로.

- 본문(Page 5)은 방화벽 처리량을 "약 150Mbps"로 쓰고, 퀴즈 u11-l02-p05-q02는 "200Mbps"로 쓴다. 둘 다 "가정"이지만 숫자가 달라 초보자가 헷갈릴 수 있다. 수치 변경 금지 지침이라 그대로 둠.
