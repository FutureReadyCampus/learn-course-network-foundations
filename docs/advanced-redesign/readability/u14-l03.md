# U14 Lesson 3 문장 가독성 수정 기록 (IPsec 두 장비의 약속)

- 수치(문장 수 / 평균 / 최대 / 70자 초과): 전 100 / 40.2 / 82 / 7 -> 후 126 / 33.3 / 82 / 3 (남은 3개는 모두 「🧠 이번에 쓴 생각법」 상자 문장)
- 고친 문장 약 40개(본문 36, 퀴즈 4), 나눈 문장 약 28개 (문단 수 44·Page 6·퀴즈 12·question_placements 6 그대로)
- 풀이를 더한 용어: IKE(키 교환 협상), SA(합의 결과 메모, 두 SG가 기억), PSK(Pre-Shared Key), ESP(내용을 감싸 보호하는 방식), AH(인증 헤더), IP 헤더(주소가 적힌 부분), SSL/TLS VPN(웹 암호화 방식인 TLS를 쓰는 VPN), 기밀성·무결성·인증(Lesson 1 정의를 한 구절로 상기)
- 기술 사실 유지: AH는 IP 헤더까지 검증하므로 NAT 뒤에서 못 쓴다, NAT-T는 ESP를 UDP 4500으로 감싸고 AH를 구제하지 않는다, 협상은 UDP 500에서 시작해 NAT 감지 시 4500으로 이동
- 손대지 않은 곳: 표 4개(구조·열 유지), 「가져갈 것」·「생각법」 상자, 퀴즈 보기·feedback 대부분(정답·길이 균형 보호), 첫 Page 도입(낯선 단어를 일부러 나열한 문장), 주소·포트 수치
- 기술 확신이 없어 보고할 문장: 없음
