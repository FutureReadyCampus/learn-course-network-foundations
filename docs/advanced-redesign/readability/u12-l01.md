# U12 Lesson 1 문장 가독성 수정 기록

- 수치(문장 수 / 평균 / 최대 / 70자 초과): 전 110 / 42.6 / 140 / 15 -> 후 131 / 36.8 / 140 / 6 (최대 140자는 "서버가 고장 난 게 아니라..." 인용과 「생각법」 상자 항목이 한 줄로 합쳐 세어진 측정 착시이고 본문 문장이 아니다)
- 고친 문장 약 25개, 나눈 문장 약 20개 (문단 수·퀴즈 수·question_placements 그대로)
- 풀이를 더한 용어: LAN, WAN, 방화벽, RFC 1918(인터넷 표준 문서), ipconfig/ifconfig, 부수 효과, 라우팅, DHCP, NAS
- 손대지 않은 곳: 퀴즈 보기·feedback 대부분(이미 짧고 보기 길이 균형·정답 의미 보호), 표 셀, 「가져갈 것」·「생각법」 상자(형식 유지), 비유 문단(짧은 문장 위주)
- 퀴즈 수정: p02 q02 prompt에 NAS 풀이 한 구절만 추가

## 대표 수정

1. Page 1 (AI 서버는 왜 사무실에서만 열릴까?): "안쪽(LAN)과 바깥쪽(WAN)은 서로 다른 네트워크다." -> "안쪽은 LAN(Local Area Network, 사무실 안의 좁은 네트워크)이다. 바깥쪽은 WAN(Wide Area Network, 건물 밖으로 이어지는 넓은 네트워크)이다. 둘은 서로 다른 네트워크다." / 처음 나오는 약어 풀이, 문장마다 개념 하나.
2. Page 1: "박 팀장이 실패한 이유는 서버 고장이 아니라, 공유기 바깥에서 안쪽에서만 통하는 주소를 쓴 데 있다." -> "...서버 고장이 아니다. 공유기 바깥에서, 안쪽에서만 통하는 주소를 썼기 때문이다." / "쓴 데 있다" 추상 표현을 풀고 두 문장으로 분리.
3. Page 1: "사무실 안에서 ...통하지만, 건물 밖에서 ...알 수 없다." -> "...통한다. 하지만 건물 밖에서 ...알 수 없다." / 비유의 대조를 두 문장으로.
4. Page 2 (192.168 주소는 밖에서도 통할까?): "사설 IP는 ...주소라서 ...있을 수 있고, 인터넷은 ...길 안내 대상으로 삼지 않는다." -> 세 문장으로 분리, "길 안내 대상으로 삼지 않는다" -> "길을 안내하지 않는다" / 한 문장에 개념 셋과 "~로 삼다" 명사구.
5. Page 2: "공인 IP는 ...관리되며, 한결디자인의 ...통신사가 회선에 배정해 주는 인터넷에서 전달되는 주소다." -> "...관리되는 주소다. ...통신사가 회선에 배정하며, 인터넷에서 전달된다." / 수식어 5개가 이어진 문장 분리.
6. Page 2: "방화벽이 막을 수 있기 때문이다." -> "방화벽(허용·차단 규칙으로 통신을 거르는 장치)이 막을 수 있기 때문이다." / 처음 나오는 용어 풀이.
7. Page 3 (이 주소, 사설일까 공인일까?): "Windows의 ipconfig나 ...가 보여 주는 것은 ...사설 주소다. 반면 ...서버가 본 주소, 곧 공유기가 NAT를 거치며 바꿔 단 바깥 주소를 보여 준다." -> 명령 풀이 한 문장 추가, 두 번째 문장을 "...본 주소를 보여 준다. 이 주소는 공유기가 NAT로 바꿔 단 바깥 주소다."로 분리 / 명령 이름 풀이와 긴 동격 절 정리.
8. Page 4 (40명이 주소 하나로 어떻게 인터넷을 쓸까?): "공유기를 나가는 요청의 출발지를 ...바꾸고, 누가 보낸 요청인지 기록해 둔다." -> "공유기는 나가는 요청의 출발지를 ...바꾼다. 그리고 누가 보낸 요청인지 기록해 둔다." / 주어를 세우고 동작 둘을 나눔.
9. Page 5 (NAT 뒤에 있으면 안전한 걸까?): "...전달할 곳이 없기 때문에 생기는 부수 효과다." -> "...전달할 곳을 모르기 때문이다. 막으려는 의도 없이 따라오는 결과, 곧 부수 효과다." / "부수 효과" 용어 풀이와 "~때문에 생기는" 군더더기 제거.
10. Page 5: "포트 포워딩은 ...적는 일이고, 뒤에서 볼 UPnP는 ...적는 일이다." -> 두 문장으로 분리 / 대조되는 두 개념을 문장 하나씩.
11. Page 6 (박 팀장에게 뭐라고 설명할까?): "공유기는 길을 안내하는 라우팅, 주소 변환, 주소 배정, 무선 접속 같은 기능이 한 상자에 든 장비이고, NAT는 ...일 뿐이다. 안내 데스크가 ...다른 일이듯이 말이다." -> "라우팅(길 안내), 주소 변환, 주소 배정(DHCP), ...든 장비다. NAT는 ...일 뿐이다. ...그 셋은 서로 다른 일이다. 공유기도 마찬가지다." / 80자 넘는 문장 분리, DHCP 이름 연결(표의 DHCP를 미리 풀이).
12. Page 6: "IPv6 회선은 ...갖는 경우가 많은데, 그때도 ...정한다." -> 두 문장으로 분리 / "~는데" 연결 정리.

## 보고할 점
- 기술적으로 확신 없는 문장은 없음(사실·수치·주소·보기 모두 그대로).
- Page 3의 "통신사 공유 주소 대역(100.64)" 문장은 이 Lesson에서 풀이하지 않고 뒤 Lesson으로 미루는 원문 구조를 유지했다.
