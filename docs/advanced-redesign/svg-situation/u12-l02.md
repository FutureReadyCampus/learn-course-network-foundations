# U12 L02 상황 SVG (생성기 `scripts/svg_pairs/u12_l02_story.py`)

Page마다 한 줄: 장면 요약 / 말풍선과 본문 근거 / `after_paragraph` / 남은 한계. 파일은 `assets/animations/u12-l02-p0P-story-<slug>.svg`.

- P1 reply-ticket: 지우 모니터에 티켓 두 건(서 이사의 질문, 박 팀장의 요청) / 박 팀장 "공유기 주소로 보낸 요청이 사라졌어요", 서 이사 "동시에 올려도 답이 안 섞이는 이유가 궁금해요" = 첫 문단의 두 티켓을 줄여 쓴 것(직접 인용 아님) / 0 / 대사가 본문의 요약문이다.
- P2 numbers-differ: 지우 PC 요청의 안쪽 출발지 `192.168.10.41:3000`과 바깥쪽 `198.51.100.25:53001` 카드 두 장, 지우 생각 "같은 요청인데 숫자가 다르다 도대체 어디가 바뀐 걸까?" = 본문 첫 문단 / 0 / 개념 SVG와 숫자가 겹친다(질문만 던지게 함).
- P3 same-ip-log: 서 이사가 접속 기록을 열고 직원 전원 `198.51.100.25`, 말풍선 "이 IP로 누가 썼는지 알 수 있나요?" = 본문 인용 앞부분 / 0 / 둘째 문장(거래처 자료)은 길어서 뺐다.
- P4 table-columns: 지우가 NAT 세션 목록의 Local·Remote·External 열을 보고 낯설어함, 생각 "열 이름이 낯설다 무엇이 어디에 적힐까?" = 본문 첫 문단 / 0 / 장면이 아니라 화면 상황이라 사람 말은 없다.
- P5 reply-arrives: 저장소의 응답 카드(목적지 `198.51.100.25:53001`), 지우 생각 "공유기는 이 응답을 어떻게 지우 PC로 돌려보낼까?" = 본문 첫 문단 질문 / 0 / 본문에 티켓 대화가 없어 질문 중심.
- P6 two-pcs: 지우 PC(.41)·동료 PC(.43)가 같은 저장소에 요청, 저장소 기록 출발지 둘 다 `198.51.100.25`, 생각 "둘 다 출발지가 똑같은데 답은 어떻게 안 섞일까?" = 본문 첫 문단 / 0 / 동료는 인물 없이 PC로만 표시.
- P7 groupware-blocked: 박 팀장이 거래처에서 `198.51.100.25:8080` 접속, 화면 "열리지 않음", 지우 생각 "요청은 공유기에 도착하는데 화면은 왜 안 나타날까?" = 본문 첫 문단 / 0 / 박 팀장은 대사 없이 표정과 화면으로만 표현, 거래처 배경은 사무실 배경으로 대신했다.
