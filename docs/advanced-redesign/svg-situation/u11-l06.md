- **P1** `p01-story-unreadable-capture` — 사무실, 박 팀장(플러그인 모니터)·서 이사·지우. 말풍선: 서 이사 "그거 고객 도면을 통째로 밖에 보내는 거 아니에요?"(P1 문단 0 대사 그대로, "우리"만 뺌), 지우 생각 "이 요청에 이것이 들어 있었다고 답하자"(문단 0 "'이 요청에 이것이 들어 있었다'고 답할 방법"). after_paragraph 1(문단 1이 지우의 시험 환경 장면, 기존 개념 그림은 2). 한계: 패킷 캡처 장면 자체는 개념 그림 몫이라 질문 알약에만 둠.
- **P2** `p02-story-local-relay` — 지우의 테스트용 PC, 플러그인이 AI 서비스로 바로 가는 선(편지 아이콘) 뒤 "?"로 바뀜. 지우 생각 "내가 볼 수 있는 누군가를 먼저 거치게 하자"(문단 0 "지우가 들여다볼 수 있는 누군가를 먼저 거치게"). 말풍선 대신 생각풍선 하나. after_paragraph 0(기존 1, 3). 한계: 통역사 비유는 그림에 넣지 않음.
- **P3** `p03-story-proxy-down` — 지우가 프록시 칸에 `127.0.0.1:8080`을 적고 도구를 켜지 않아 "프록시 서버에 연결할 수 없습니다"(문단 0 인용). 생각 "도구 하나 꺼졌을 뿐인데 왜 전부 끊겼지?"(문단 0 질문 줄임). after_paragraph 0(기존 2, 3). 한계: 도구가 꺼진 모습은 모니터 오류로만 암시하고 도구 화면은 그리지 않음.
- **P4** `p04-story-cert-warning` — 지우, 요청 목록 모니터가 "내용 푸는 옵션 켬"에서 오류로, 경고 카드 "연결이 비공개로 설정되어 있지 않습니다"(문단 0 인용). 생각 "도구는 처음엔 못 열고, 열려고 하면 경고가 날까?"(문단 0 마지막 질문). after_paragraph 0(기존 1, 3). 배경 client는 다른 Page와 겹치지 않게 고른 것이고 본문 장소는 아님. 한계: 터널 한 줄 요청은 글로 옮기지 않음.
- **P5** `p05-story-two-screens` — 캡처 도구·프록시 도구 화면 두 개를 지우가 나란히 봄, "수천 줄의 패킷" 대 "요청 한 줄"(문단 0). 생각 "도면을 통째로 보내는지 답하기 쉬운 쪽은?"(문단 0 질문). after_paragraph 0(기존 3, 4). 한계: 본문에 대사 없음, 상황과 소품으로만 구성.
- **P6** `p06-story-three-proxies` — 서버실 배경(회사 프록시가 서버실에 있다는 본문 설정), 지우와 "분석 결과"(문단 0 "분석 결과를 정리하던") 뒤 세 프록시 상자(무료 우회·회사·로컬). 생각 "정말 셋은 다른 물건일까?"(문단 0 마지막 질문). after_paragraph 0(기존 2). 한계: 문단 끝 서 이사의 질문은 다음 Lesson 예고라 쓰지 않음. 세 상자 단계의 새 글자 3개는 이름뿐, 장소·관리자는 개념 그림과 표에 맡김.

공통: 실제 도구 이름 없음, 주소는 장부 값(`127.0.0.1:8080`)만 사용, 본인 PC·가짜 데이터 범위.
