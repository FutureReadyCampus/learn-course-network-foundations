# Unit 12 Lesson 3 상황 SVG (포트 포워딩)

생성기 `scripts/svg_pairs/u12_l03_story.py`. 파일 `units/08-router-and-nat/lessons/restructured/03-*/assets/animations/u12-l03-p0N-story-*.svg`. 모든 Page `after_paragraph`는 0(기존 그림은 모두 0 이상이라 오름차순 유지).

| Page | 장면 요약 / 말풍선과 본문 근거 / 한계 |
| --- | --- |
| 1 규칙-줄 | 박 팀장 결재 희망 -> 지우가 "바깥 8080 -> 그룹웨어 서버" 한 줄 -> 서 이사 질문(본문 대사 그대로). 한계: 서 이사가 3단계에 등장해 부제는 박 팀장의 요청만 언급. |
| 2 칸 채우기 | 메뉴를 연 지우 -> 다섯 칸(본문 열거) -> 잘못 채울까 걱정(본문 "엉뚱한 곳 또는 어디로도"). 본문에 대사 없어 생각 풍선만. 한계: 칸 값은 일부러 비워 둠(개념 SVG 몫). |
| 3 어떤 주소 | 규칙은 넣었다 -> 사설 주소 `192.168.10.50:8080`은 바깥에서 안 통함 -> 지우의 고민. 한계: 정답 주소는 일부러 숨김, 박 팀장은 대사 없음. |
| 4 둘째 요청 | 그룹웨어 규칙 -> 직원들이 공유 자료 NAS도 열어 달라 -> "규칙을 하나 더 넣으면 될 것 같다". 한계: 직원은 말 없이 소품과 알약으로만 표현. |
| 5 사무실 시험 | 사무실에서 `198.51.100.25:8080` 실패 -> "규칙이 틀렸나?" -> 집에서 시험한 직원은 열림(본문 요약 대사). 한계: 직원 대사는 본문 문장을 말투만 바꿈. |
| 6 안 열림 | 휴대폰 데이터로 시험해도 실패 -> "규칙은 분명히 넣었는데". 한계: 확인 표 4단계는 개념 SVG 몫이라 넣지 않음, 장면이 가장 단순. |
| 7 누가 들어올까 | 점검 끝 -> 서 이사 "8080을 열면 박 팀장만 들어와요?"(본문 대사) -> 질문이 다시 떠오름. 한계: 위험 설명은 개념 SVG 몫. |
