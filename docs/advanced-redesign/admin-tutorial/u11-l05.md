# Unit 11 Lesson 5 관리자 튜토리얼 기록

방향: 지우 = 신입 네트워크 관리자, 박 팀장 = 요청하는 직원, 서 이사 = 비용·보안 결정권자. 서비스 대응: 외부 AI 서비스 -> 외부 클라우드 저장소(`files.example`, 203.0.113.80), 고객 도면 -> 거래처 자료. 기술 설명, learn-page-id, 퀴즈 ID·개수·정답, 주소·포트는 그대로다. Lesson 제목: '고객 도면이 AI로 새지 않게' -> '거래처 자료가 밖으로 새지 않게'. 생성기: `scripts/svg_pairs/u11_l05_story.py`, `u11_l05_new_scenes.py --svg-only`, `u11_l05_rev.py --svg-only`.

- Page 1 (방화벽으로 우회 막기): 박 팀장이 고객 도면을 AI에 올림 -> 거래처 견적 자료 PDF를 집에서 보려고 개인 클라우드에 올림. 퀴즈: q2 AI API 호출 스크립트 -> 매일 밤 도는 외부 클라우드 저장소 백업 스크립트(보기 b·d 문구 맞춤). SVG: story-block-bypass(재작성), fw-rules·rule-order(변경 없음). 한계: 없음.
- Page 2 (프록시 기록): 어제 AI에 올린 것 찾기 -> 어제 클라우드 저장소에 올린 것 찾기, 8MB는 거래처 자료 PDF인지 사진 묶음인지 모른다. 퀴즈: q1·q2의 AI 서비스·디자인팀 PC -> 클라우드 저장소·영업팀 PC. SVG: story-log-question(주소 교체), proxy-log(라벨 교체). 한계: 없음.
- Page 3 (TLS 검사): 암호화된 AI 대화 -> 암호화된 업로드(Page 제목 포함). 퀴즈: q1 AI 서비스 -> 클라우드 저장소. SVG: story-open-chat(라벨 교체, 파일명 open-chat 유지), tls-inspect(라벨 교체), trust-list(주소 교체). 한계: 파일명에 chat이 남음.
- Page 4 (파일 검사): AI 자동 배치 플러그인 -> 파일 동기화 프로그램 설치 파일. 퀴즈: q2 도면 자동 변환 도구 -> PDF 변환 도구. SVG: story-plugin-download(라벨 교체, 파일명 plugin 유지), file-scan(라벨 교체). 한계: 파일명에 plugin이 남음.
- Page 5 (한 상자 통합 장비): 웹과 AI만 느림 -> 웹만 느림(본문·표·퀴즈 보기·그림 모두). 퀴즈: q2 "웹·AI 서비스부터" -> "웹 서비스부터". SVG: story-one-box, combined-box(라벨 교체). 한계: 느려지는 이유(프록시 기능의 TLS·파일 검사 부하)는 그대로라 AI 특성 의존 없음.
- Page 6 (감시 범위): AI 대화 전문 1년 보관 -> 직원이 주고받은 내용 전문(메일 본문·올린 파일) 1년 보관, 개인 내용 예시는 점심 약속·병원 예약·개인 메일(Page 제목도 '직원의 통신 내용, 어디까지 봐도 될까?'). 퀴즈: q1 AI 대화 전문 -> 웹메일·저장소 내용 전문, q2 외부 AI 번역 도구에 지원자 서류 -> 개인 계정 외부 클라우드 저장소에 지원자 서류 업로드(보기 전부 맞춤, 정답 구조 동일). SVG: story-monitoring-limit, log-scope(재작성·라벨 교체). 한계: 웹메일 이야기가 Page 6에서 처음 나와 앞 Page의 클라우드 저장소 흐름과 약간 섞인다.
