# Unit 11 Lesson 6 관리자 튜토리얼 기록

방향: 티켓 넷째(새로 깔린 프로그램이 뭘 보내는지). 서 이사가 박 팀장 PC에 새로 깔린 파일 동기화 프로그램이 거래처 자료를 밖으로 보내는지 확인해 달라고 요청하고, 지우가 로컬 프록시로 확인한다. AI 플러그인 -> 파일 동기화 프로그램, 외부 AI API -> 외부 클라우드 저장소(`203.0.113.80:443`), 평면도·도면 -> 견적서 파일·거래처 자료. Lesson 제목: "새 프로그램이 실제로 보내는 것 읽기: 내 PC의 로컬 프록시". 기술 설명·learn-page-id·퀴즈 ID·개수·정답·폴더 이름은 그대로다. 생성기: `scripts/svg_pairs/u11_l06_story.py`, `u11_l06_new_scenes.py --svg-only`, `u11_l06_rev.py --svg-only`.

- Page 1: AI 자동 배치 플러그인·고객 도면 걱정 -> 티켓 넷째, 파일 동기화 프로그램(용어 풀이 추가)과 서 이사의 확인 요청. 퀴즈: q1 평면도 파일·AI API 요청·가구 배치안 -> 견적서 파일·클라우드 저장소 요청·업로드 결과, q2 마케팅팀 AI 이미지 서비스 문장 -> 영업팀 외부 클라우드 저장소 견적서 파일. SVG: story-unreadable-capture(재작성), capture-limit(라벨 교체). 한계: 없음.
- Page 2: 설계 플러그인·가짜 평면도 -> 동기화 프로그램·가짜 견적서. 퀴즈: q1 보기 외부 AI API -> 외부 클라우드 저장소, q2 디자인팀 신입의 진짜 고객 도면 -> 영업팀 신입의 진짜 거래처 자료. SVG: story-local-relay(재작성), local-relay, scope, local-proxy(라벨 교체; local-proxy는 lesson.md에 연결 안 된 옛 파일). 한계: 없음.
- Page 3: 플러그인 -> 동기화 프로그램, AI 서비스 -> 저장소 서비스. 퀴즈: q1 보기 외부 AI API -> 외부 클라우드 저장소, q2 변경 없음. SVG: story-proxy-down(변경 없음), loopback-port(변경 없음), upstream(라벨 교체). 한계: 없음.
- Page 4: AI 서비스 -> 저장소 서비스(HTTPS 풀기 원리는 그대로). 퀴즈: q1 AI 서비스 개인 키 -> 저장소 서비스 개인 키, q2 외부 AI 채팅·AI 도면 정리 플러그인 -> 외부 클라우드 저장소 웹 화면·파일 동기화 프로그램, 장애 공지 보기도 같이 교체. SVG: story-cert-warning(변경 없음), two-tls(라벨 교체), root-trust(변경 없음). 한계: 없음.
- Page 5: 도면을 통째로 보내는가 -> 견적서를 통째로 보내는가(base64 4MB 설명은 그대로 맞음). 퀴즈: q1 변경 없음, q2 AI 색상 추천 플러그인·시안 이미지 -> 다른 파일 동기화 프로그램·견적서 이미지 2MB, 본문 30KB. SVG: story-two-screens(문구 교체), stream-view(변경 없음), base64-size(문구 교체, 마지막 말풍선 폭 확장). 한계: 실제 클라우드 저장소는 대개 multipart 업로드라 JSON+base64 본문은 예시용 가정.
- Page 6: 표(우회·회사·로컬)는 그대로. 끝 장면: "회사 안에 AI를 두면" -> "자료 서버를 회사 안에 두고 밖에서 쓰게 열어 두면"(11-7 리버스 프록시 티켓 다섯째로 연결). 퀴즈: q2 AI 요청 중계 서비스 -> 파일 업로드 중계 서비스, 보기 AI 서비스 수 -> 클라우드 서비스 수. SVG: story-three-proxies, three-proxies(변경 없음). 한계: 없음.
