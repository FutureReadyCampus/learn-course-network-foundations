# U11 L5 어려운 용어 점검 기록

비유: 회사 출입 경비(U11 L6 Page 4와 같은 말). 인증서=신분증, CA=도장 찍어 주는 기관, 신뢰 목록=경비실 명단. L5 Page 3에서 먼저 도입하고 L6이 이어받는다. L6 본문은 건드리지 않았다.

| 용어 | Page | 왜 어려운가 | 처방 |
| --- | --- | --- | --- |
| 192.168.10.0/24 | 1 | /24 표기 | ① 사내 PC들이 속한 주소 범위 |
| QUIC, DNS 조회 | 1 | 풀이 없음 | ① 한 구절씩 |
| 병목 | 1 | 추상어 | ① 한 좁은 길목에 몰려 느려지는 곳 |
| 포트 80/443 | 1 | 표에서 풀이 없음 | ① 평문 웹 / 암호화 웹의 문 |
| TLS, 프록시 사용자 인증 | 2 | 풀이 없음 | ① 한 구절씩 |
| 인증서, CA, 신뢰 목록, 서명, 공개/개인 키 | 3 | "이전 Unit에서"라며 풀이 없이 나옴(L6과 같은 문제) | ③ 출입 경비 비유 문단 + 용어 풀이(SVG는 L6 Page 4의 것과 같은 내용이라 추가 안 함, 기존 p3b 신뢰 목록 그림이 있음) |
| 회사 CA, 인증서 고정 | 3 | 비유와 연결 안 됨 | ② 회사가 파서 쓰는 도장 / 경비실 명단 / "이 인증서만 믿는다" |
| Stream | 4 | 풀이 없음 | ① 이어져 흐르는 연결 |
| 검사 대기열 | 5 | 낯섦 | ① 검사를 기다리는 줄 |
| 고지 | 6 | 법률투 | ① 미리 알리는 |

## 결과
- 고칠 곳은 Page 3에 집중, 나머지는 한 구절 풀이. Page 3 문단 2개 추가(기존 문단 유지), SVG·퀴즈 after_paragraph를 +2.
- 퀴즈·정답·learn-page-id·SVG 파일 불변.
