# U11 L6 "도구" 이름 고정

- 로컬 프록시 프로그램 = **분석 프록시**. Page 2에서 소개(PC에 설치해 켜 두면 127.0.0.1:8080에서 대기하는 프록시 서버, 요청·응답을 한 건씩 목록으로 표시). mitmproxy, Fiddler, Burp Suite, Charles는 이 소개에서 한 번만 언급.
- 패킷 캡처 = **패킷 캡처 프로그램**. Page 1에서 "Wireshark 같은" 예와 "길 위를 지나는 패킷을 그대로 찍는 프로그램" 풀이를 한 번만 둠.
- 본문·퀴즈·page_metadata·가져갈 것은 '도구'를 위 이름으로 치환하고 조사를 고침. Page 4 첫머리에 "분석 프록시(로컬 프록시 프로그램)" 환기를 추가, 연결 ①②는 "앱과 분석 프록시 / 분석 프록시와 저장소 서비스"로 통일.
- SVG는 생성기(u11_l06_story/rev/new_scenes.py)의 글자를 고쳐 --svg-only로 재생성(story.py는 항상 SVG만 씀). 주의: rev.py·new_scenes.py를 --svg-only 없이 돌리면 lesson.md의 illustrations 블록을 덮어쓴다.
- 남은 '도구': Page 6 퀴즈 해설 "통제 도구인지 위험인지"(일반 의미) 1곳.
