# U11 L6 인증서 설명 보강 기록

비유: 회사 출입 경비. 인증서 = 신분증(주소·공개 키·발급 기관 도장), CA = 도장 찍어 주는 기관, 신뢰 목록 = 경비실 명단, 확인 둘 = ①도장 기관이 명단에 있나 ②이름이 찾아간 주소와 같나. 루트 인증서 = 도장의 뿌리, 인증서 고정 = "이 얼굴만 들여보낸다".

- Page 1: TLS 설명 문단에 "암호로 말하기 전에 하나 더 확인(인증서), 자세한 건 Page 4" 예고 두 문장 추가(문단 수 불변).
- Page 2: 상태 코드, 로그인 토큰에 한 구절씩 풀이.
- Page 3: 상위 프록시 칸에 풀이 한 구절.
- Page 4: 첫 문단 뒤에 인증서 설명 블록 4문단(비유 + 지우 문제 풀이) 추가, 새 SVG `u11-l06-p04-cert-id-card.svg`를 블록 끝(after_paragraph 4)에 배치. 기존 문단은 도장·명단 용어로 이음(인증서 고정, 루트 인증서, 개인 키 풀이). 기존 SVG 둘은 유지, after_paragraph를 5·7로, 퀴즈 배치를 8로 이동.
- Page 5: 복호화·루트 인증서 문장을 도장/신뢰 목록 용어로 이음.
- Page 6: Stream 풀이 한 구절. 표 TLS 행은 그대로 읽혀 수정 없음.
- SVG: 생성기 `scripts/svg_pairs/u11_l06_cert.py`. "도구가 만든 신분증 -> 경고 -> 명단 추가" 흐름은 기존 `p04b-root-trust`로 충분해 추가하지 않음.
- 퀴즈·정답·learn-page-id 변경 없음. 용어집에 인증서·CA 항목 없음.
