# U14 L2 어려운 용어 점검 기록

이미 택배·구매 대행 이중 포장 비유가 전 Page에 있고 쉬운 편이다. 설명 블록·SVG는 만들지 않고 한 구절 풀이만 더했다(문단 수 불변, illustrations 불변).

| 용어 | Page | 왜 어려운가 | 처방 |
| --- | --- | --- | --- |
| G-to-G, SG | 1 | 앞 Unit 약어, 풀이 없음 | ① 한 구절 풀이 |
| 터널 처리 | 1 | 가리키는 동작이 모호 | ② 패킷을 포장해 터널로 보내는 일 |
| 새 IP 헤더 | 2 | 헤더가 무엇인지 환기 없음 | ① 송장 같은 앞머리 |
| 복호화 | 4 | 처음 나오는데 풀이 없음 | ① 암호를 원래대로 되돌리는 일 |
| 암호화를 맡는 헤더 | 3 | 이름 없이 가리킴 | ② ESP 헤더 |
| 방화벽 | 4 | 앞 Unit 전제 | ① 규칙으로 가려내는 경비 |
| ISP | 5 | 약어 | ① 통신사(ISP) |
| L3 터널링, L2, IPsec | 5 | 계층 번호·규격명 풀이 없음 | ① 한 구절씩 |
| DF 비트, 재전송, 연산 | 6 | 풀이 없음 | ① 한 구절씩 |

## 결과
본문만 수정. 퀴즈·정답·page id 불변. 가장 약한 곳: Page 5의 터널 모드/전송 모드는 "이름만 알아 두자"로 남김.
