# Unit 11 Lesson 1 관리자 튜토리얼 시범 기록

방향: 지우 = 신입 네트워크 관리자(직원 약 40명 회사), 박 팀장 = 요청하는 직원, 서 이사 = 비용·보안 결정권자. 요청은 "티켓"으로 부른다.
티켓 다섯 건(Page 순서): 1 회사에서만 특정 사이트가 안 열려요(Inline, 11-2) / 2 누가 어떤 사이트를 많이 쓰는지(Out of path, 11-3) / 3 거래처 자료가 개인 클라우드에 올라가는지(포워드 프록시, 11-4·11-5) / 4 새로 깔린 프로그램이 뭘 보내는지(로컬 프록시, 11-6) / 5 회사 서버를 밖에 열어 두면 안전한지(리버스 프록시, 11-7).
기술 설명, Page 제목, learn-page-id, 퀴즈 ID·개수·정답은 그대로다. 생성기: `scripts/svg_pairs/u11_l01_story.py`, `u11_l01_rev.py --svg-only`.

- Page 1: AI 도입·시안 설명문·메모 다섯 장 -> 신입 관리자와 티켓 다섯 건(뒤 Lesson은 주제 이름만 연결). 퀴즈: q2 감사팀 요청의 대상을 외부 AI 서비스 -> 외부 클라우드 저장소로. SVG: story-first-week(재작성), three-structures, five-memos(티켓 순서 재배열, 파일명 유지). 한계: five-memos 파일명에 memo가 남음.
- Page 2: 서 이사의 특정 AI 사이트 차단 질문 -> 특정 사이트 차단 요청 + 첫 번째 티켓 연결. 퀴즈: q2 디자인팀 AI 이미지 사이트 -> 영업팀 거래처 자료 공유 사이트. SVG: story-block-request(재작성), inline-drop(라벨 교체). 한계: 203.0.113.80은 장부의 외부 AI 서비스 주소를 외부 사이트로 재사용.
- Page 3: 누가 어떤 AI를 쓰나 -> 누가 어떤 사이트를 많이 쓰나. 퀴즈: q2 AI 코딩 도구 업로드 경고 -> 외부 클라우드 저장소 대용량 업로드 경고. SVG: story-just-watch(재작성), out-of-path-copy(라벨 교체). 한계: 없음.
- Page 4: 고객 도면 유출 걱정 -> 거래처 자료의 개인 클라우드 업로드 확인 요청. 퀴즈: q2 3D 시안 파일 -> 40MB 견적 자료 파일(외부 클라우드 저장소). SVG: story-drawing-worry(재작성), proxy-two-connections, https-ca(라벨 교체). 한계: 개인 클라우드와 외부 클라우드 저장소 주소(203.0.113.80)가 같은 하나로 그려짐.
- Page 5: AI 플러그인 -> 파일 동기화 프로그램(용어 풀이 추가). 퀴즈: q1 플러그인 설치 파일 -> 프로그램 설치 파일, q2 AI 회의록 요약 도구 -> 파일 동기화 프로그램. SVG: story-plugin-question(재작성), header-vs-content(문구 교체). 한계: 없음.
- Page 6: 새 보안 장비 설명서 + 서 이사의 "업무에 안 맞는 사이트는 막고 업무용은 열어 주세요" 문장 추가. 퀴즈: 변경 없음(AI 내용 없음). SVG: 변경 없음. 한계: 이 요청 문장은 본문에만 있고 그림에는 그리지 않음.
