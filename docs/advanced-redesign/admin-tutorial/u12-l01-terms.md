# Unit 12 Lesson 1 초보자 용어 점검

방법: Page 1부터 6까지 한 Page씩 읽고, 처음 나오는데 풀이가 없거나 어려운 말을 찾았다. 이 Lesson에서 이미 풀어 둔 말(그룹웨어 서버, LAN/WAN, 사설/공인 IP, 방화벽, NAT 비유, 라우팅, DHCP 등)은 건드리지 않았다. 처방 ①=한 구절 풀이, ②=구체적 이름으로 바꾸기, ③=비유 블록.

| 용어 | Page | 왜 어려운가 | 처방 |
| --- | --- | --- | --- |
| 티켓 | 1 | 업무 용어, 풀이 없음 | ① 요청 한 건을 적어 둔 업무 접수 카드 |
| `:8080` 포트 번호 | 1 | 주소 뒤 콜론 숫자가 처음 나오는데 설명 없음 | ① 서버 안에서 그룹웨어 화면을 맡은 창구 번호 |
| 패킷 | 2 | 앞 Unit 개념을 전제 | ① 주소를 붙여 보내는 데이터 묶음 |
| 감염 PC | 2 | "감염"이 막연 | ① 악성 프로그램이 깔린 PC |
| `/8` `/12` `/16` | 3 | 슬래시 표기를 풀이 없이 사용 | ① 앞쪽 몇 비트까지가 네트워크 구분인지 나타내는 표기(이전 Unit) |
| NAT | 3 | 설명(Page 4)보다 먼저 등장 | ① 출발지 주소를 바꿔 다는 공유기 기능, 다음 Page에서 자세히 |
| 통신사 공유 주소 대역(100.64) | 3 | 추상적 | ① 통신사가 가입자 여러 명에게 같이 쓰게 하려고 따로 떼어 둔 범위 |
| 출발지 | 4 | 앞 Unit 개념 | ① 패킷을 보낸 쪽 주소 |
| 포트 번호(기록에 포함) | 4 | 왜 포트를 기록하는지 모름 | ① 한 기기 안에서 어느 프로그램의 통신인지 가리키는 번호 |
| 패킷, 감염된 PC | 5 | 위와 동일 | ① 데이터 묶음 / 악성 프로그램에 감염된 PC |
| UPnP | 5 | 앞질러 나온 약어, 정의 없음 | ① 프로그램이 공유기에 길을 열어 달라고 직접 요청하는 기능 |
| IPv6 | 6 | 약어 | ① IPv4보다 주소 수가 훨씬 많은 새 주소 방식 |

③ 비유 블록·개념 SVG: 만들지 않았다. 어려운 개념(사설/공인 주소, NAT, NAT 부수 효과)은 이미 건물 내선, 아파트 동·호수, 대표 전화 교환원, 방문객 대장 비유로 끝까지 풀려 있고, 남은 것은 모두 한 구절로 해결되는 용어였다. 본문 문단 수 불변이라 `after_paragraph`·퀴즈·Page 구성은 그대로다.
