# U15 Lesson 2 SVG 점검 (AI 서버로 가는 문, 누구에게 열어 줄까: 방화벽)

생성기: `scripts/svg_pairs/u15_l02_rev.py` (옛 `u15_l02_firewall.py`, `u15_l00_common.py`는 import만). 옛 SVG(`u15-l02-p1~p7-*.svg`)는 파일만 남기고 Page에서 뺐다.
한 예시: 박 팀장 PC `192.168.10.42` → AI 서버 `192.168.10.50`이 서버 구역 `192.168.40.50:8080`(방화벽 전용 포트 뒤)으로 이동. 패킷은 아이콘 뒤로 지나가고, 주황 테두리는 방금 바뀐 요소만.
