# U13 L3 (DNS 기반 부하 분산과 GSLB) SVG 점검

생성기: `scripts/svg_pairs/u13_l03_rev.py` (기존 `u13_l03_gslb.py`는 수정하지 않음). 새·고친 9개 SVG의 4단계 프레임을 모두 렌더해 확인했고, 유지한 3개(p1·p2·p7)도 4프레임을 확인했다.

| Page | 판정 | 이유 | 파일 | 남은 한계 |
|---|---|---|---|---|
| 1 일본 고객에게만 한결봇이 왜 느릴까? | 유지 | 서버는 한산한데 왕복이 쌓여 느리다는 핵심이 4단계에 보임, 1단계도 비지 않음 | u13-l03-p1-latency | 2단계에서 패킷과 라벨이 함께 바뀜 |
| 2 DNS가 주소를 둘 알려 주면 해결될까? | 유지 + 하나 더 | 라운드 로빈은 상태를 모른다는 그림은 맞음. 본문 3번째 문단과 q01·q02의 TTL 캐시는 그림에 없어 두 번째 그림 추가 | u13-l03-p2-dns-rr, u13-l03-p2b-ttl | p2b는 손님→캐시→사이트를 한 줄로 단순화 |
| 3 이름 하나로 지역마다 다른 주소를 주려면? | 교체 | 1단계가 사람과 상자 하나뿐이고 글자 15px. 빈 칸(?)으로 흐름을 먼저 보이고 4단계에서 지역마다 다른 주소를 보임 | u13-l03-p3-cname-steps | 4단계 상자 안 글자가 16~17px로 작음 |
| 4 DNS는 손님이 어디 있는지 어떻게 알까? | 교체 + 하나 더 | 옛 그림은 결과 비교만 있고 "리졸버 주소를 본다"(q01)·ECS가 없었고 4단계 알약이 겹침. 원리 그림(p4)과 노트북/PC 비교(p4b)로 나눔 | u13-l03-p4-resolver-ip, u13-l03-p4b-resolver-fix | ECS는 손님 주소 앞부분을 값 없이 말로만 표시(공인 주소를 지어내지 않음) |
| 5 IP 주소만 보고 나라를 알 수 있을까? | 수정 + 하나 더 | 1단계에 빈 칸(어느 나라?)을 넣고 글자를 키움. 본문 4번째 문단(안내 vs 약관)과 q02(해외 IP 차단)가 그림에 없어 추가 | u13-l03-p5-geoip-steps, u13-l03-p5b-guide-vs-block | p5 1~2단계 아래쪽이 비어 있음(3단계에 VPN 줄이 들어옴) |
| 6 서울과 도쿄의 한결봇이 다른 답을 한다면? | 교체 | 손님이 패널과 이어지지 않았고 복사 선이 40px라 짧았음. 손님별 응답, 원본 복사, 응답의 버전 번호 순으로 재구성 | u13-l03-p6-sync-steps | 3단계에서 버전·응답이 함께 바뀜(복사의 결과) |
| 7 사진과 화면은 더 가까이 둘 수 없을까? | 유지 + 하나 더 | 에지 캐시와 개인 응답 제외는 그대로 좋음. q02(고친 사진이 예전으로 보임)에 맞춰 예전 사본과 hero-v2.jpg 그림 추가 | u13-l03-p7-cdn, u13-l03-p7b-stale-copy | p7b는 삭제 요청(purge)을 그리지 않고 파일 이름 버전만 보임 |
| 8 지역을 고른 뒤엔 누가 서버를 고를까? | 교체 | 4단계에서 서울 장애가 나도 일본 손님만 있어 GSLB가 돌리는 모습이 안 보였음. 한국·일본 손님 둘로 지역 선택→L4→서버 1대 고장→서울 전체 장애 순으로 | u13-l03-p8-two-layers-rev | 4단계에서 서울 장애와 새 경로가 한꺼번에 바뀜 |
