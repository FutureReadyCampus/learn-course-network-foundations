# U14 Lesson 4 SVG 점검 (집에서 사내 AI 열기: 원격 접속 VPN)

생성기: `scripts/svg_pairs/u14_l04_rev.py` (옛 `u14_l04_remote_vpn.py`는 import만 하고, 옛 SVG `u14-l04-p?-*`는 파일만 남기고 Page에서 뺌).
색 규칙: 안쪽 헤더 파랑, 바깥 헤더·터널 보라, 통과 초록, 막힘 빨강, 주황은 방금 바뀐 요소만. 움직이는 패킷은 장치·인터넷 아이콘 뒤로 지나가며 라벨 위를 지나지 않음.
공통 수정: 글자 14~15px였던 곳을 16px 이상으로(보조 주소 라벨만 15px), 하단 pill을 패널에서 떼어 놓고, 단계당 추가 라벨 3개 이하.
