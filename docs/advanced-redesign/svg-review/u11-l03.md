# U11 Lesson 3 SVG 점검 (경로 밖 관찰과 DPI)

생성기: `scripts/svg_pairs/u11_l03_rev.py` (`u11_new_common.py`·`kit.py`는 import만, 옛 `u11_l03_oop.py`는 건드리지 않고 옛 SVG `u11-oop-*`는 파일만 남기고 Page에서 뺌).
한 가지 예시: 지우 PC 192.168.10.41 / 박 팀장 PC 192.168.10.42 → 코어 스위치 → 게이트웨이 192.168.10.1 → 인터넷, 옆에 센서 192.168.10.250, 외부 AI 서비스 203.0.113.80:443.
색 규칙: Inline 파랑, 복사·센서 보라, 정상·✓ 초록, ✗·위험 빨강, 주황은 방금 바뀐 요소만. 움직이는 패킷은 장치 아이콘 뒤로 지나간다.
