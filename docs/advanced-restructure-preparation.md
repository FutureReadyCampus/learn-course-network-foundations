# Unit 11~15 구조 적용 준비

이 문서는 [콘텐츠 #163](https://github.com/FutureReadyCampus/learn-course-network-foundations/issues/163)의 **준비 단계 결과**다. 승인된 목차는 5 Unit·20개 기술 Lesson이다. 실제 목차·원고·Learn 데이터는 변경하지 않았다. [Learn #223](https://github.com/FutureReadyCampus/learn/issues/223)의 4 Unit·18 Lesson 설명은 이 승인안으로 갱신해야 한다. 구조 적용과 본문 개선은 각각 후속 작업이다.

## 조사 기준과 스냅샷

- 콘텐츠 stage: `4269969b0021fa85a3ab55c73c1dde6a66334c75`.
- Learn main 조사: `f0b56c641919e9aa25fe421375b9553e05935dfa`. 로컬 main은 뒤처져 있어 원격 추적 커밋의 파일을 직접 읽었다. 운영 동작을 확인한 것은 아니다.
- [대응 스냅샷](advanced-restructure-snapshot.json)은 감사 자료다. `target_key`와 `audit_page_key`는 내부 대응 키이며 현재 API의 Lesson/Page ID가 아니다. 빌더·importer는 이 파일을 읽지 않는다.
- 23개 원고에서 빌더가 만드는 화면은 203개다. 기술 원고 194개는 20개 목표 Lesson에, 안내 8개와 자료 1개는 비학습 자료에 대응한다. 인쇄용 원고는 H2가 없어도 빌더의 fallback 화면 하나가 생성된다.
- 원본 파일 해시, 빌드된 페이지 JSON 해시, 22개 SVG 자산의 해시, 출처, 구 stage/Learn 경로, 새 위치를 고정했다. 인쇄 PDF 두 개는 원래 링크를 기록했으며 내려받거나 공개 저장소에 복사하지 않았다. 접근 권한과 링크 응답은 이번에 확인하지 않았다.
- 기준 심화 원고의 질문 ID는 0개다. 실제 수강자의 과거 답안·완료 상태는 조사하지 않았다. 완료 기록이 없다고 추정하지 않으며 후속 검증은 합성 fixture와 기존 저장 계약을 기준으로 한다.
- 모든 원본 화면에 목적지를 한 번씩 배정했다. 원고 통합은 최종 페이지 수 축소를 뜻하지 않는다. U13의 기술 전망과 기존 VPN 악용 원고는 참고 역할로 표시했다.

Flash의 제안 중 ‘15 Unit이면 즉시 오류/전체 소멸’은 확인된 코드 영향보다 과해 채택하지 않았다. ‘필수 1분 안내’, VPN을 모두 같은 계층·암호화로 한정하는 비유, 자유 진입이 이미 가능한 듯한 안내도 채택하지 않았다.

## Learn에 넘길 최소 동작 계약

다음은 구조 적용 전에 구현·검증할 요구사항이다. 현재 배포 기능이나 확정된 API 필드 이름을 뜻하지 않는다. 실제 필드명·라우트 판본·canonical ID는 양 저장소의 구현 PR에서 스냅샷과 함께 고정한다.

1. **그룹과 비학습 자료:** 기본편과 선택 심화를 목차에 구분한다. 안내는 기존 8화면의 원문을 보존하면서 짧은 진입 설명과 상세 읽기를 제공한다. 자료는 제목·원문/출처·PDF 링크를 전달하며 Lesson 공개/이수 집합과 분리한다. 기존 source ID는 이력으로 남긴다.
2. **Lesson·Page 정체성:** 1:1 Lesson은 기존 ID를 유지한다. 병합·분할 대상은 기존 ID·원본 페이지·새 ID의 명시적 대응을 마련한다. 표시 제목과 원고 경로를 바꿨다는 이유로 기존 기록을 삭제하지 않는다. 감사 키를 곧바로 production ID로 사용하지 않는다.
3. **주소와 읽던 위치:** stage의 버전 없는 주소와 Learn `/v2` 주소를 서로 다른 출발 주소로 취급한다. 구주소는 고정된 원 Lesson/Page를 먼저 찾고 그다음 새 위치를 정한다. 안내·자료는 해당 비학습 위치로 간다. 같은 숫자를 새 목차에 바로 대입하지 않는다. 모호하거나 매핑되지 않은 주소는 엉뚱한 본문으로 자동 이동하지 않는다. 저장된 이어 학습하기도 같은 대응표를 사용한다.
4. **기록 보존:** 원본 행·append-only 이벤트·완료 증거를 보존한다. 새 목차의 집계와 원본 기록을 구별한다. N:1 병합에서 일부 원고 완료를 전체 완료로 확대하지 않으며, 1:N 분할에서 명시적 완료 증거가 없는 원고를 완료로 만들지 않는다. 기존 전체 완료를 분할 대상에 재사용할 때에는 원문 범위가 그대로인지 확인하고 출처 기록을 남긴다. 질문 ID가 없는 읽기 화면에서 `all([])`만으로 과거 열람·완료를 추정하지 않는다.
5. **답안과 공개 설정:** 기존 질문 ID·답안·통과 집합과 원래 필수 질문을 보존한다. 브라우저 대기 답안은 새 소유 Lesson을 확인하기 전 다른 질문으로 재전송하지 않는다. 병합/분할된 Lesson의 공개 상태는 기존 부분 공개 상태를 확대하지 않도록 별도 확인한다. 새 Lesson을 importer의 기본 공개 목록에 넣는 것만으로 공개 의도가 검증된 것은 아니다.
6. **기본편 완료와 자료:** 심화 미완료와 자료 미열람이 기본편 완료를 취소하지 않게 한다. 기존 UI의 전체 완료 수를 기본편 수료로 간주하지 않고 실제 계산·표시를 검증한다.

### 아직 결정하지 않은 진입 방식

사용자에게 ‘기본편 이후 심화 Unit 자유 선택 + Unit 안 순차 진행’과 ‘심화도 Unit 11→15 순차 진행’을 질문했다. 답변 전까지 자유 진입을 구현하거나 학습자 안내에 약속하지 않는다. 이 선택은 스냅샷·원문 대응 검증에는 영향을 주지 않는다.
